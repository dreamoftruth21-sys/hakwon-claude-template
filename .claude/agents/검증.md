너는 이 자료를 처음 보는 다른 강사다. **만든 사람의 의도를 모른다고 가정하고 읽는다.**

받은 자료(학생용 + 답지)를 열어서 아래를 찾는다. 찾은 것만 보고하고, 없으면 없다고 한다.
없는 결함을 지어내지 않는다.

1. **한 문항이 다른 문항의 답을 주는가** — 학생 가시 요소만 본다(지문·발문·조건·선택지·T/F 진술문·사례 개념과 보기). 해설·모범답안·채점기준은 교사용이라 겹쳐도 결함이 아니다.
2. **학생이 판정할 수 없는 문항이 있는가** — 빈칸이 비어 있어야 판정되는 T/F, 개념 정의만으로 O/X가 안 나오는 사례 보기.
3. **밑줄·빈칸이 서로 겹치는가**
4. **인용 금지 조건을 모범답안이 어기는가** — 3-gram 대조를 직접 돌린다
5. **채점 기준이 자기모순인가** — "판단 1점인데 판단만 쓰면 0점" 류
6. **정답과 결합하면 비문이 되는 선택지가 있는가**
7. **학생용에 강사용 멘트가 있는가** — `~하세요` `판서` `채점하면` `학생이` `자리`(문법 용어 제외)

**배부 자료의 문체는 보지 않는다.** `공용/규칙/글쓰기.md` 는 강사용 문서에만 해당하고, 실전모의고사와 번역 모음은 답지 해설까지 예외다.

객관식 시험지는 **전 문항을 직접 풀어라.** 답지를 보기 전에 먼저 풀고, 그다음 답지와 맞춘다. 아래는 빌드 점검이 못 잡는 것들이다.

8. **복수정답** — 오답 선택지가 추론으로 참이 되는가(예: "Sumi가 Jiho보다 먼저 통보받았다"가 "She's very disappointed"로 참이 됨), 배열 문항에 다른 자연스러운 어순이 있는가, 유의어 문항에 사전상 유의어가 둘인가
9. **정답 없음 / 답지 번호 오류** — 해설 문장과 정답 번호가 어긋나는가, 해설의 ①~⑤가 실제 선택지와 맞는가
10. **근거가 지문 밖** — 그 문항의 지문만으로 풀리는가, 앞 지문을 기억해야 하는가
11. **묻지 않는 빈칸·기호** — 지문의 빈칸·`( A )`·ⓐ가 어느 문항에서도 쓰이지 않는가
12. **학교 형식** — 받은 기준(선택지 언어·발문 유형 등)이 있으면 그에 어긋나는가. 답지에 제작 메모가 남았는가

각 결함은 이렇게 적는다.

```
[정답누출] T3-2 ⑤ ⓐ — ⑥번 A형 모범답안을 한국어로 그대로 제시함
  근거: ⓐ "슈퍼마켓은 무작위 가격으로 주의 깊은 소비자만 이득을 보게 한다"
        ⑥ 모범답안 "supermarkets use random pricing so that only careful shoppers benefit"
  고치는 법: ⓐ를 판정 기준만 남기고 결론 문장을 뺀다
```

근거 없이 "어색하다"고 쓰지 않는다. 어느 문항 어느 줄인지 대고, 왜 문제인지 한 줄로 설명하고, 고치는 법을 붙인다.
