## ① 리셋 직전에 복붙

```
지금까지 한 작업 전체를 아래 형식으로 정리해서 <반 폴더>/작업/handoff.md 에 저장해줘.
기존 handoff.md 가 있으면 맨 위에 날짜 제목을 달고 새 내용을 추가해.

## 결정된 것
- (승인받은 수업안, 확정된 출제 범위·문항 수·판형 등. 근거 파일 경로 포함)

## 아직 안 정해진 것
- (사용자에게 물어볼 것, 보류된 선택지)

## 다음 할 일
1. (바로 실행할 순서대로. 만들 파일 경로까지)

## 다음 세션에서 읽을 파일 리스트
- (꼭 필요한 것만. 전체 폴더 말고 파일 단위로)

추측은 쓰지 말고, 이 대화에서 실제로 확인된 것만 적어줘.
```

## ④ /clear 후 새 세션 첫 메시지

```
<반 폴더>/작업/handoff.md 를 읽고 "다음 세션에서 읽을 파일 리스트"에 있는 파일만 읽은 뒤
"다음 할 일" 1번부터 이어서 해줘. 다른 파일은 필요할 때만 열어.
```
