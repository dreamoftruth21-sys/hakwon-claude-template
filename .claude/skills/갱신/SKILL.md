# 템플릿 갱신

저장소: `https://github.com/dreamoftruth21-sys/hakwon-claude-template`
- 새 판 zip: `https://github.com/dreamoftruth21-sys/hakwon-claude-template/archive/refs/heads/main.zip`
- 옛 판 zip: `https://github.com/dreamoftruth21-sys/hakwon-claude-template/archive/refs/tags/<태그>.zip` (태그 예: `판-2026-10-19`)

작업은 스크래치 폴더에서 한다. 선생님 폴더에는 승인 뒤에만 쓴다.

## 1. 판 확인
- 지금 판: `공용/판_지문.json` 의 `태그`. 이 파일이 없으면(넷째 판 이전) `공용/VERSION.txt` 첫 줄의 날짜로 `판-<날짜>` 로 한다.
- 새 판 zip 을 내려받아 푼다. 새 판 `공용/VERSION.txt` 첫 줄이 지금 것과 같으면 "이미 최신입니다"로 끝낸다.
- 옛 판 zip(지금 판의 태그)을 내려받아 푼다. 그 태그가 없다고 나오면 옛 판 없이 간다(아래 2단계에 `-`).

## 2. 선생님이 고친 파일 찾기 (프로그램이 한다)
**새 판의** 스크립트로 돌린다 — 지금 판에는 이 스크립트가 없을 수 있다.
```
py <새판 폴더>/공용/판지문.py 대조 <옛판 폴더> <새판 폴더> <선생님 폴더>
```
(옛 판이 없으면 `<옛판 폴더>` 자리에 `-`)
출력은 다섯 가지로 나온다.
| 분류 | 뜻 | 할 일 |
|---|---|---|
| 덮어쓰기 | 선생님이 안 고친 파일 | 새 판으로 바꾼다. 묻지 않는다 |
| 유지 | 선생님이 고쳤고 새 판에서는 안 바뀐 파일 | 선생님 것을 그대로 둔다. 묻지 않고 보고만 한다 |
| **충돌** | 선생님도 고치고 새 판도 바뀐 파일 | **3단계에서 묻는다** |
| 새파일 | 새 판에 새로 생긴 파일 | 넣는다. 묻지 않는다 |
| 삭제됨 | 옛 판에는 있었는데 선생님 폴더에 없는 파일 | 새 판 것을 넣는다 |
| 추가 | 선생님이 만든 파일(새 스킬 등) | 그대로 둔다 |

## 3. 보여 주고 승인받기
한 번에 보여 준다: 새 판 번호와 한 줄 설명(VERSION 첫 줄) · 덮어쓰는 파일 수 · 유지 파일 이름 · 충돌 파일.
충돌 파일은 **하나씩**, 대조 출력의 「선생님이 바꾼 줄」(`+` 줄)을 그대로 보여 주고 셋 중 하나를 고르게 한다:
- **새 판으로** — 선생님이 바꾼 줄이 사라진다. 그 줄이 규칙이면 `공용/규칙/우리학원.md` 나 반 `CLAUDE.md` 로 옮겨 줄지 같이 묻는다.
- **지금 것 유지** — 새 판의 수정이 이 파일에는 안 들어간다.
- **합치기** — 새 판 파일을 넣은 뒤 선생님이 바꾼 줄을 같은 자리에 다시 넣는다. 끝나면 그 부분을 보여 준다.
충돌이 없으면 "선생님이 고친 템플릿 파일은 없습니다"라고 한 줄 말하고 승인만 받는다.
**"좋아" 같은 분명한 승인 전에는 선생님 폴더에 아무것도 쓰지 않는다.**

## 4. 덮어쓰기
- 2단계 분류대로 쓴다. 유지 · 추가 파일과 충돌에서 「지금 것 유지」로 답한 파일은 건너뛴다.
- 대상 폴더: `.claude/skills/` · `.claude/agents/` · `.claude/prompts/` · `.claude/settings.json` · `공용/build/` · `공용/규칙/` · `공용/온라인채점/`(코드) · `공용/사용기록/`의 `.py` 와 `수신주소.txt` · `공용/정리/` · `공용/판지문.py` · `공용/판_지문.json` · `_새반_틀/` · `README.md` · `공용/VERSION.txt`
- **반 폴더마다** `.claude/settings.json` 을 넣는다 — 루트 바로 아래, `_` 로 시작하지 않고 `CLAUDE.md` 가 있는 폴더 전부에 `_새반_틀/.claude/settings.json` 을 복사한다(있으면 새 판으로 바꾼다). 사용 기록 훅이 반 폴더에서 돌게 하는 것이다.
- `공용/온라인채점/README.md` 는 새 판으로 바꾸되 「링크」 절의 웹 앱 URL · 배포 ID · 시험 링크 줄은 지금 것을 그대로 옮겨 넣는다.

## 5. 건드리지 않는 것
반 폴더 전부(위 `.claude/settings.json` 만 예외) · `공용/규칙/우리학원.md` · `공용/설정상태.json` · `공용/사용기록/기록/` · `공용/사용기록/상태.json` · `공용/온라인채점/채점키/` · `해설/` · `정정/` · `제안/` · `apps_script/.clasp.json` · `공용/build/학교/` 의 `_예시.json` 밖 파일 · `.claude/skills/자료정리/rules.ps1` · `무시목록.txt` · 새 판에 없는 스킬 폴더(선생님이 만든 것) · 대조에서 「추가」 · 「유지」로 나온 파일
