# 서술형 채점 제안

구조는 `공용/온라인채점/README.md` "선생님 메뉴 · 탭". **점수를 확정하지 않는다** — 제안만 만들고, 선생님이 시트 `서술형 채점` 탭 `득점 ✎` 칸에 넣는다.

## 1. 채점 대기 답 가져오기

- 드라이브 도구로 `온라인채점` 스프레드시트를 찾아(`search_files` · `title = '온라인채점'`) xlsx 로 받는다(`download_file_content`, exportMimeType `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`). 결과가 크면 저장된 파일을 python(openpyxl)으로 연다
- `서술형 채점` 탭을 읽는다. A열 `줄 번호` 가 제안 파일의 키다 (`제출 시각|시험|이름|시도|번호`)
- 탭이 비었거나 오래됐으면 선생님께 시트 메뉴 **[온라인채점 → 서술형 채점 탭 새로 고침]** 을 먼저 눌러 달라고 한다
- TEST 는 없다 (탭에서 이미 뺀다)

## 2. 문항별 채점 근거

- 탭의 `모범답안` · `채점 기준`(조건 포함) · `배점`
- 더 필요하면 `공용/온라인채점/채점키/<시험ID>_채점키.json` 의 그 문항 `criteria` · `exp`, 원본 `data` 경로의 data.json(지문)

## 3. 제안 쓰기

- 점수: 0 ~ 배점, 0.1 단위. **채점 기준의 요소별 점수를 그대로 따른다.** 기준에 없는 관대함·가산 금지
- 이유: 80자 안팎. 기준 요소마다 있음/없음을 적는다. 예: "① 금전적 대가 있음 ② 행동 변화 없음 · 3단어 연속 인용(give up the habit) 부분 제외"
- 판단이 애매하면 낮은 쪽 점수 + 이유 끝에 "확인 필요"
- 조건(단어 수·지정어·한 문장·우리말/영어) 위반은 기준에 적힌 대로만 깎는다
- 철자·문법 오류는 기준에 언급이 있을 때만 반영

## 4. 파일에 저장

`공용/온라인채점/제안/온라인채점_서술형제안.json` (드라이브와 동기화된다 — 시트가 이 이름으로 찾는다)
```json
{"2026-09-30 14:03:11|한솔고2_실전3회|김OO|1|서답형 2": {"score": 2.4, "why": "① 있음 ② 없음"}}
```
- 이미 있는 파일에 **덧붙인다** (기존 키는 지우지 않는다. 같은 키는 새 제안으로 바꾼다)
- 저장 뒤 선생님께: 1~2분 뒤 **[서술형 채점 탭 새로 고침]** 을 누르면 `제안 점수`·`제안 이유` 가 채워진다. 확정은 `득점 ✎` 칸에

## 5. 보고

학생·문항별 제안 점수 요약 표 (시험 · 이름 · 번호 · 제안 / 배점 · 한 줄 이유), "확인 필요" 표시 문항을 맨 위에.
