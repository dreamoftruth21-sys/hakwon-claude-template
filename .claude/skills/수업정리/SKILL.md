# 오늘 수업 정리

**새 자료를 만들지 않는다.** 이미 정해진 것(수업안·수업일지·오늘 수업 폴더)을 모아 아래 형식으로 내놓는다.
반 폴더 세션에서 쓴다. 반 폴더가 아니면 어느 반인지 먼저 묻는다.

## 1. 오늘 무엇을 하는지 찾는다 — 이 순서로

1. `date` 로 오늘 날짜·요일 확인. 이 반 `CLAUDE.md` 의 요일과 대조 (나성중3은 월수 · 화목 · 금 통합 중 어느 슬롯인지)
2. **오늘 수업 폴더 `<MMDD요일>/수업안.md`** — 수업준비 스킬이 승인 후 만든 것. 있으면 이것이 기준이다
3. 없으면 **`수업일지.md` 의 오늘 날짜 항목**
4. 둘 다 없으면 **최근 항목 하나**에서 가져온다 — `숙제 (냄)` → 오늘 숙제 확인, `다음` → 오늘 진도.
   이 경우 맨 위에 **"오늘 수업안이 없어 지난 일지로 추정했습니다"** 한 줄을 적고, 오늘 숙제는 "(정해지지 않음)"으로 둔다. 추정으로 숙제를 지어내지 않는다.

## 2. 자료 파일 찾기

오늘 수업 폴더 `<MMDD요일>/` 의 번호로 나눈다.

| 항목 | 파일 |
|---|---|
| 숙제 확인 | 지난 수업 폴더의 `4_*` (지난번 내준 숙제 파일 자체) + 오늘 폴더의 `2_*` (그 답지) — 답지만 보내지 않는다 (2026-10-14 지정) |
| 진도 | `1_*` (단어시험·답지) · `3_*` (수업 자료) |
| 숙제 | `4_*` (`4_내줄숙제_…` — 2026-10-14부터 이 이름. 그 전 폴더는 `4_숙제_…`) |

수업 폴더가 없거나 비어 있으면 `시험대비/<시험>/배부/` · `단어시험/배부/` 에서 수업안·일지에 적힌 이름으로 찾는다.
**교재(책)로 하는 것**은 파일이 없다 — "(교재: 내신콘서트 부록 5과 2회)"처럼 적는다. 파일이 있어야 하는데 못 찾으면 "(파일 없음)"으로 적는다. 비슷한 이름 파일로 대신하지 않는다.

보내기 전에 `Get-ChildItem` 으로 실제 파일명을 확인한다.

## 3. 출력 형식 — 이대로

```
[확인용]
숙제 확인: (지난번에 내준 숙제)

진도: (오늘 해야 할 것들 — 순서대로)

숙제: (오늘 내줄 숙제 · 언제까지)

자료 링크:
- 숙제 확인 — 파일명 (답지)
- 진도 — 파일명 · 파일명
- 숙제 — 파일명

[주간보고서 기입용]
진도:

숙제:
```

그리고 **자료 링크의 항목마다 파일 카드를 따로 보낸다** — `SendUserFile` 을 항목별로 한 번씩, `caption` 에 "숙제 확인용" / "진도용" / "숙제용". 파일이 없는 항목은 카드를 보내지 않는다.

### [확인용] 쓰는 법
- 선생님이 수업 직전에 훑어보는 용도. 짧게, 한 항목에 한두 줄
- 재시험 대상·미제출자는 기록에 있을 때만 이름을 붙인다 (`학생.md` 에 있는 이름만)

### [주간보고서 기입용] 쓰는 법 — `행정/주간리포트/Weekly Report` 칸에 그대로 붙여 넣는 문장
- 실제 주간리포트 말투를 따른다: 명사형으로 짧게 이어 쓴다. 예 `단어 : 프린트 추가 단어 (접두사 포함)  추가 문장·추가 지문 해석, 워크북 순서대로`
- **진도**: 맨 앞에 `단어 : <단어시험 범위>` (시험이 있을 때) → 그다음 수업 내용. 약한 부분이 기록돼 있으면 괄호로 (`관계부사, 영영풀이 추가 학습 필요`)
- **숙제**: 내준 숙제 그대로 + 기한. 방법 지시가 있었으면 덧붙인다 (`*한 파트씩 풀고 채점·수정 후 다음 섹션`)
- 점수·학생 이름·파일명은 넣지 않는다
- 기록에 없는 내용을 채우지 않는다
- **이 칸은 `공용/규칙/글쓰기.md` 의 예외다.** 실제 주간리포트 양식이 명사형이라 주어·서술어가 없고 "-기" 꼴이 그대로 들어간다. 문장으로 펴지 않는다

## 하지 말 것
- 수업안이 없는데 오늘 할 일을 새로 정하지 않는다 — 그건 `수업준비` 스킬의 일이다. 필요하면 "수업 준비부터 할까요?"라고 묻는다
- 다른 반 폴더를 읽지 않는다
- 영어로 쓰지 않는다
