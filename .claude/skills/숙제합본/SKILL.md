# 숙제 합본

숙제 파일이 여러 개면 따로 인쇄하기 번거롭다. 한 파일로 합쳐 한 번에 뽑게 한다.
**새 숙제를 정하거나 만들지 않는다.** 이미 수업 폴더에 있는 `4_내줄숙제_*.pdf` 만 합친다.

## 순서

1. 수업 폴더를 정한다 — 오늘 날짜의 `<MMDD요일>/`. 반 폴더 세션이 아니면 어느 반인지 묻는다
2. `Get-ChildItem` 으로 `4_내줄숙제_*.pdf` 를 확인한다. 수업안의 "낼 숙제"와 파일이 다르면 합치기 전에 말한다
3. 합친다

   ```
   py ../공용/build/쪽뽑기/숙제합본.py <수업폴더>        (학원 폴더에서는 py 공용/build/쪽뽑기/숙제합본.py <반>/<수업폴더>)
   ```
   → `<수업폴더>/4_내줄숙제_합본_양면인쇄.pdf`
   숙제 답지도 한 파일로 모은다 (2026-10-02 지정) — 그 숙제를 확인하는 날의 폴더에 `2_숙제확인_…_답지.pdf` 가 있으면
   ```
   py ../공용/build/쪽뽑기/숙제합본.py --답지 <다음 수업 폴더> [<폴더>…]
   ```
   → `<폴더>/2_숙제확인_합본_답지.pdf` (숙제 합본과 같은 순서. 교사용이라 표식 없음)
4. 첫 쪽 위쪽을 렌더해서 삼각형이 내용과 겹치지 않는지 본다
5. 브라우저 패널에 띄우고 파일 카드로 보낸다. 쪽수와 양면 장수를 한 줄로 적는다 (`16쪽 · 양면 8장`)

## 스크립트가 하는 일

- `4_내줄숙제_*.pdf` 를 이름순으로 합친다 (이전 합본은 빼고)
- **인쇄는 항상 양면이다.** 전체 쪽수가 홀수면 끝에 빈 쪽을 붙인다 — 여러 부를 이어 뽑아도 다음 부가 앞면에서 시작한다
- 첫 쪽 **위 양쪽 모서리(오른쪽·왼쪽)** 에 회색 삼각형(변 약 18mm, 직각이 종이 모서리)을 찍는다 — `첫쪽표식.py` 와 같은 표식이다. 낱개 숙제 파일에는 찍지 않는다 (찍혀 있으면 합본이 멈춘다) — 인쇄 더미에서 한 부씩 스테이플러로 찝을 때 다음 부의 첫 장을 찾는 표식이다
- 위 모서리에 내용이 있으면 그쪽 삼각형만 아래 모서리로 내린다. 위아래 다 막히면 멈춘다

## 하지 말 것

- 숙제가 바뀌었는데 옛 합본을 그대로 두지 않는다 — 다시 돌린다
- 표식을 검은 사각형으로 바꾸지 않는다 (2026-10-02 회색 삼각형으로 지정)
- 답지(`2_숙제확인_…`)를 숙제 합본에 넣지 않는다 — 답지는 답지끼리 따로 합친다
