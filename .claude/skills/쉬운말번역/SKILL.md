# 쉬운 말 번역 (영문 지문 분석 및 번역 모음)

**선생님이 요청할 때만 만든다** (2026-10-28 Danny). 회차 폴더에 이 문서가 없어도 수업 준비 · 다른 자료 제작 중에 만들지 않고, 묻지도 않는다.

모고로 수업하는 **모든 반이 먼저 참고하는 강사용 문서**다. 회차별 파일 목록과 공용 폴더 주의사항은 `공용/교재/모의고사/README.md` — **먼저 읽는다.**
기준 견본: `공용/교재/모의고사/2025_고2_9월/Translation_and_Analysis.docx` (32·34·36·40번)

## 결과물

`공용/교재/모의고사/<연도_학년_월>/<반>_<연도>-<월>학평_쉬운말번역.docx` — JSON의 `filename` 에 이 이름을 넣는다 (규칙은 README)
JSON의 `title` 에 **반·연도·회차**를 넣는다 — `"양지고2 · 2025년 9월 고2 학평 · 영문 지문 분석 및 번역 모음"`. 없으면 빌드가 멈춘다. 쪽 아래 `N / 전체` 쪽번호는 빌더가 넣는다.
데이터 `…/작업/쉬운말번역.json` · 미리보기 `…/작업/Translation_and_Analysis.pdf`

한 회차에 파일 하나. 번호를 추가하면 JSON에 지문을 더하고 **통째로 다시 빌드**한다.
**여러 반이 같은 회차 폴더를 쓰면** 반별 데이터 작업/쉬운말번역_<반>.json 을 두고 빌드에 --data 쉬운말번역_<반>.json 을 붙인다 — 다른 반의 쉬운말번역.json 을 덮어쓰지 않는다 (예: 2025_고2_10월 양지고2).

## 0. 대상 확인

번호가 정해져 있으면 바로 만든다. 번호 없이 "만들어줘"라고만 하면 반별 범위(각 반 `CLAUDE.md`)에서 후보를 제안하고 승인을 받는다.
회차 폴더에 기존 docx가 있고 JSON이 없으면 먼저 가져온다:

```
py .claude\skills\쉬운말번역\scripts\build.py "<회차폴더>" --import "<기존.docx>"
```

가져온 지문은 `source`·`en` 이 비어 있어 검증에 걸린다. 원문을 채워 넣는다.

## 1. 원문 확보

```
py .claude\skills\쉬운말번역\scripts\extract.py "<회차폴더>\…문제지.pdf" 24 29
```

- 발문·선택지·주석(`* cash nexus: …`)은 빼고 **지문 본문만** `source` 에 넣는다.
- 밑줄 번호 ①~⑤, (A)(B)는 남겨 둬도 대조에서 걷힌다.
- 문제지가 스캔본이거나 없으면 지문분석·백지노트 PDF에서 받아 적는다.
- **어법 문항 지문은 틀린 선지를 고친 형태로 번역한다** (예: 29번 ⑤ which → where). 원문 `source` 는 시험지 그대로 둔다.

## 2. 문장 나누기

`sentences` 는 **원문 한 문장 = 한 항목**. 이어 붙이면 `source` 와 같아야 한다(빌드가 검사).
- 마침표·물음표·느낌표에서 나눈다.
- 콜론 뒤에 붙은 질문(`…apps: Why does …?`)은 앞 문장과 한 항목으로 둔다.
- 따옴표 안 문장은 인용 전체를 한 항목으로.

## 3. 내용 쓰기 — 견본의 결을 따른다

| 칸 | 쓰는 법 |
|---|---|
| **제목** | `title_ko` 한국어 제목 + `title_en` 영어 제목. 제목 문항이면 정답 선지를 참고하되 그대로 베끼지 않는다 |
| **주장·전개·결론** | 각 1~2문장. `-다` 체. 전개는 글이 실제로 드는 사례·대조를 구체적으로 |
| **한 줄 요약** | 한 문장. 주장과 결론을 잇는다 |
| **쉬운 말 번역** | 아래 |

**쉬운 말 번역 원칙**
- 원문 문장 순서·개수 그대로. 한 항목에 두 문장이 들어가도 되지만 원문 한 문장을 둘로 쪼개 번호를 늘리지 않는다.
- 직역이 아니라 **고2가 한 번에 알아듣는 말**로. 추상어는 풀어 쓰고 필요하면 원어를 괄호로: `본능적인 생각(인지적 동기)`
- 원문에 생략된 맥락은 괄호로 채운다: `(학생들의 주의력을 지키기 위해)`
- 이해를 돕는 일상 예시는 괄호 한 문장으로 덧붙인다: `(중고차를 살 때 정말 갖고 싶어도 관심 없는 척하는 것처럼 말이다.)` — 지문마다 1~2개, 남발하지 않는다
- 지문에 없는 사실·주장을 만들어 넣지 않는다. 예시는 이해 보조로만
- `-다` 체. 구어 표현(`밀당`, `꼼수`)은 뜻이 더 잘 전달될 때만
- **"자리" 표현 금지** (문법 용어 제외), 강사용 멘트 금지 — 빌드가 검사한다
- **이 문서는 `공용/규칙/글쓰기.md` 의 예외다** — 분석 칸도 번역문도 적용하지 않는다. 위의 쉬운 말 번역 원칙이 우선이다 (2026-09-23 지정)

## 4. 빌드

```
py .claude\skills\쉬운말번역\scripts\build.py "<회차폴더>"
```

검증(하나라도 걸리면 문서를 만들지 않는다):
- 모든 칸이 채워졌는가 · 번호 중복·순서
- **원문 대조** — 문장을 이으면 원문과 글자 단위로 같은가 (문장 누락·병합 방지)
- "자리" 표현 · 강사용 멘트

기존 docx는 `작업/…_이전.docx` 로 백업한 뒤 새로 쓴다.

## 5. 점검과 전달

- 미리보기 PDF를 렌더해서 본다 (`자체점검` 스킬 6항).
- 원문 문장 수와 번역 항목 수를 지문별로 보고한다.
- 루트 `CLAUDE.md` 의 규칙대로 **PDF를 브라우저 패널에 띄우고, docx를 파일 카드로 보낸다.**
- 새 회차 파일이나 번호를 추가했으면 `공용/교재/모의고사/README.md` 표를 고친다.
