# 시험지 분석

**한 학교 이야기만 한다.** 다른 학교와 비교하지 않는다 (루트 CLAUDE.md 규칙).

산출물은 해당 반 `분석/출제경향.md` 하나에 누적한다. 새로 분석할 때마다 장을 이어 붙인다
(예: 나성중3의 "6장 L5 학습지 분석", "7장 L5-6 모의고사 제작 기록"). **기존 장을 지우거나 덮어쓰지 않는다.**

## 두 층위로 본다

기출 분석은 **거시**(유형·배점 구조)와 **미시**(오답이 정답에서 어떻게 만들어지는지) 두 층위가 있다.
거시만 보면 "뭐가 많이 나오는지"는 알아도 "그걸 어떻게 흉내 내야 하는지"는 모른다.
**실전 자료(모의고사·워크북)를 만들려면 미시가 반드시 필요하다.**

### 1단계 — 거시: 유형·배점·출처

기출을 구해 문항별로 표를 만든다.
- 유형별 배점 합계·회당 평균 (빈칸추론 / 내용일치 / 어법 / 함축 / 순서배열 / 문장삽입 / 서술형 등)
- 문항 순서가 고정인가 — 학교마다 다르다. 고정이면 새 자료도 그 순서를 따른다 (나성중3은 1~26번 순서가 두 회 모두 동일)
- **배점이 0인 유형이 있는가** — 그 학교는 그 유형을 아예 안 낸다는 뜻이다. 새 자료에도 넣지 않는다 (한솔고2는 순서배열·문장삽입이 두 회 모두 0점)
- 지문 출처 — 교과서 / 학평(연도·월·지문번호) / 원서 발췌 / 학교 자체 프린트. **6~n-gram 대조**(연속 여러 단어가 문장부호까지 일치)로 "이 지문은 여기서 가져왔다"를 확정한다. 짐작으로 "학평 같다"고 적지 않는다.
- 두 회 이상 있으면 **회차 간 비교**로 고정 규칙을 뽑는다 (예: "전년도 같은 달 학평이 주력, 당해년도는 일부만" / "전년도+당해년도 학평을 둘 다 쓴다"). **한 회만으로는 규칙을 확정하지 않는다** — "~인 것으로 보인다"로 남기고, 다음 회차가 들어오면 확정한다.

### 2단계 — 미시: 오답은 정답에서 어떻게 만들어지는가

**여기가 핵심이고, 실전 자료 제작에 직결된다.** 문항을 유형별로만 묶지 말고, 정답 선택지와 오답 선택지를
나란히 놓고 **글자 단위로 무엇이 바뀌었는지** 본다.

찾아야 할 것:
- 정답이 원문(프린트·교재·학평 지문) 그대로인가, 오답이 원문을 살짝 훼손한 것인가
- 훼손 방식이 **패턴화**되어 있는가 — 나성중3에서 실제로 찾은 예:
  - 예문의 전치사만 뺀다 (a chair to sit ~~on~~)
  - 동명사 ↔ to부정사를 바꾼다, 가목적어 어순을 뒤집는다
  - **영영풀이는 원문 그대로 쓰고, 핵심 단어 하나만 반대말로 바꾼다** (strong→soft, without stopping→stopping).
    정답 선택지는 문장부호까지 원문과 동일하다.
  - 어법 문항 밑줄 위치가 해석지에 인쇄된 괄호 `[ A / B ]` 위치와 거의 일치한다
  - 내용일치 오답이 지문 T/F 문항의 패러프레이즈를 재활용한다
- **반드시 실제 기출 원본(스캔 PDF·사진)을 문항 단위로 재확인한다.** 요약 정리본이나 기억만으로는 이 패턴이 안 보인다.
- 패턴을 찾으면 **"출제 공식 N가지"로 번호를 매겨 적는다** — 한 줄 요약 + 실제 문항에서 뽑은 예시 1개씩.
  **최소 2개 이상 문항에서 같은 패턴이 반복돼야 "공식"이다.** 한 문항에서만 보이면 "사례"로만 적고 공식화하지 않는다.

이 공식이 이후 실전모의고사·워크북의 오답 선택지를 어떻게 지을지 그대로 알려준다.
(`나성중3/분석/출제경향.md` 참고 — 실제 기출 문항의 오답 "a storm with very soft fast winds"가
원문의 strong을 soft로만 바꾼 것임을 확인하고, 새 모의고사의 영영풀이 문항에 같은 함정을 재현한 사례가 있다.)

## 실행 순서

1. `학교자료/기출/`에서 실제 기출 PDF·사진을 찾는다. **없으면 사용자에게 있는지 먼저 묻는다** — 기출 없이 짐작으로 분석하지 않는다.
2. 스캔 순서가 뒤죽박죽일 수 있다 — 쪽 하단에 인쇄된 쪽 번호로 정렬한다 (나성중3 사례).
3. 문항을 전부 읽는다. PDF를 Read 도구로 넘기면 이미지로 온다 — 요약하지 말고 문항 하나하나, **특히 오답 선택지까지** 눈으로 본다.
4. 1단계(거시) 표를 채운다.
5. 2단계(미시) — 정답·오답을 나란히 대조해 훼손 패턴을 찾는다.
6. `분석/출제경향.md`에 새 장으로 이어 붙인다. 기존 장은 그대로 둔다.
7. 반 `CLAUDE.md`에 요약을 반영할지 사용자에게 확인한다 — 범위·특이사항처럼 매 수업 참조할 내용이면 CLAUDE.md에도 짧게, 상세 근거는 출제경향.md에만 남긴다.

## 하지 말 것

- 다른 학교와 비교하지 않는다.
- 기출 원본 없이 "보통 이렇게 나온다"고 짐작해서 쓰지 않는다.
- 한 회차·한 문항만 보고 "공식"이라 단정하지 않는다 — 반복을 확인한다.
- 재시험 기준·커트라인을 분석 중에 임의로 만들지 않는다.
- 거시 표만 만들고 끝내지 않는다 — 미시(오답 생성 규칙)까지 가야 실전 자료 제작에 쓸 수 있다.
- 배점이 0으로 확인된 유형을 새 자료에 넣지 않는다.
