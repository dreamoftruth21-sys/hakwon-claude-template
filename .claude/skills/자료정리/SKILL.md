# 자료 정리

사용자가 "정리해"라고 하면 **확인을 구하지 말고 바로 돌린다.** 옮기기는 되돌릴 수 있고 기록이 남는다. 묻는 건 반을 판단할 수 없는 파일뿐이다.

## 절대 규칙

- **지우지 않는다.** 필요 없는 것은 `_정리대기/삭제예정` 으로 옮기고, 지우는 건 사용자가 한다.
- **덮어쓰지 않는다.** 같은 파일이면 `_정리대기/_중복`, 이름만 같으면 최신본을 제자리에 두고 나머지는 `_정리대기/_충돌`.
- **규칙에 안 맞는 파일은 건드리지 않는다.** 다운로드에는 개인 문서 · 설치파일 · 사진 같은 개인 자료가 섞여 있다. 개인 자료로 보이는 파일은 열어 보지도 않는다.
- **`학교자료` 파일 내용은 고치지 않는다.** 이름이 내용과 명백히 다를 때만 이름을 바로잡고 보고한다.

## 순서

### 1. 계획 (dry-run)

```
powershell -NoProfile -ExecutionPolicy Bypass -File ".claude\skills\자료정리\scripts\sort.ps1"
```

학원 폴더 루트에 새 자료를 넣었다고 하면 `-Source "<학원 폴더 경로>"` 를 붙인다.
Python·스크립트 경로는 루트 `CLAUDE.md` 의 실행 환경 절을 따른다.

출력에서 두 가지를 본다.
- **목적지별 개수** — 엉뚱한 반으로 가는 게 없는지 훑는다. 틀린 규칙은 `rules.ps1` 을 고치고 다시 계획을 뽑는다.
- **규칙에 안 맞은 것** — 이름만 보고 수업자료로 보이는 것을 고른다. 개인 자료로 판단한 것은 `무시목록.txt` 에 이름을 덧붙여 다음 보고에서 빠지게 한다.

### 2. 실행

```
powershell -NoProfile -ExecutionPolicy Bypass -File ".claude\skills\자료정리\scripts\sort.ps1" -Run
```

**잠김**이 나오면 사용자에게 뷰어를 닫으라고 하고, 닫았다고 하면 같은 명령을 다시 돌린다. 이미 옮긴 것은 자동으로 건너뛴다.

### 3. 규칙에 안 맞은 수업자료 판단

이름으로 반을 모르겠으면 **열어서 본다.** 추측으로 옮기지 않는다.
**3개 이상이면 직접 열지 말고 `자료분류` 에이전트(Haiku)에 파일 목록째 넘겨** 판정표를 받는다. 확신 "높음"만 옮기고 나머지는 아래 방식으로 직접 본다.
- pdf → `pymupdf` 로 첫 쪽 텍스트. 스캔본이면 첫 쪽을 png로 렌더해서 Read
- docx → `word/document.xml` 텍스트
- hwp → `olefile` 로 `PrvText` 스트림 (미리보기 텍스트)

반을 가르는 단서는 교과서 · 출판사 · 교재 이름이다. **각 반 `CLAUDE.md` 「교재」 표**를 보고 판정한다. 학평(연도 · 학년 · 월)은 `공용/교재/모의고사/<연도_학년_월>` 로 간다.

열어 봐도 모르겠으면 `_정리대기/다운로드_확인필요` 로 옮기고 사용자에게 묻는다. 손으로 옮길 때는:

```
powershell -NoProfile -ExecutionPolicy Bypass -File ".claude\skills\자료정리\scripts\put.ps1" -Src "<파일>" -Dest "세종예고2\학교자료\부교재"
```

### 4. 배운 것을 규칙에 넣는다

사용자가 "이건 ○○반 거야", "필요 없어"라고 답하면 **`rules.ps1` 에 한 줄 추가한다.** 같은 질문을 두 번 하지 않기 위해서다.
- 필요 없다 → `_정리대기\삭제예정` 규칙
- 담당 반이 아닌 학교·과목 → `_정리대기\담당외_…`
- 구체적인 규칙은 위에, 넓은 규칙은 아래에

`rules.ps1` 을 고친 뒤에는 **UTF-8 BOM으로 저장**한다. Windows PowerShell 5.1은 BOM이 없으면 한글 정규식이 깨진다.

```
$p='.claude\skills\자료정리\rules.ps1'; [IO.File]::WriteAllText($p,[IO.File]::ReadAllText($p,[Text.Encoding]::UTF8),(New-Object Text.UTF8Encoding $true))
```

### 4-1. 텍스트 변환

`학교자료` 으로 옮긴 파일이 있으면 그 반만 변환한다(이미 변환한 파일은 건너뜀).

```
py 공용/build/원본_md변환.py <반이름>
```

### 5. 새 종류의 자리가 생겼으면 CLAUDE.md를 갱신한다

학교 기출·학교 프린트·분석 문서처럼 **반 세션이 찾아야 하는 자료**가 새로 들어오면 그 반 `CLAUDE.md` 의 "자료 위치"와 "미확보"를 고친다. "미확보"였던 것이 들어오면 지운다.
단어시험지·배부 PDF처럼 폴더 규칙대로 들어간 것은 고치지 않는다.

## 보고 형식

```
다운로드 정리 끝 — 이동 42 · 중복 11 · 잠김 0

어디로 갔나
  양지고2/학교자료/기출      1학기 1·2회고사 PDF 2
  공용/교재/모의고사/2026_고2_9월   지문분석 9
  ...

확인 부탁 (_정리대기/다운로드_확인필요)
  H2_L1_WORD_TEST.pdf — 영어Ⅱ 1과인데 세종예고2·양지고2 둘 다 가능

같은 이름 다른 판 — 최신본을 제자리에 둠
  세종예고1학년_중간고사대비교재.pdf  제자리 09-02 / 구버전 08-27 → _충돌

지울 것 (직접): _정리대기/_중복 · _충돌 · 삭제예정
```

같은 이름인데 크기가 크게 다르면(예: 45MB와 16MB) 날짜만 믿지 말고 **쪽수와 첫 쪽을 비교해 다른 문서인지 확인한다.** 이름만 같은 다른 문서였던 적이 있다.

기록은 `_정리대기/정리기록/<날짜>_계획.csv`, `_이동.tsv` 에 남는다. 되돌릴 때 이걸 본다.
