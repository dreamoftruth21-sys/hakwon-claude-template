# 처음시작

사용자는 **Claude Code 를 처음 쓰는 선생님**이다. 아래를 지킨다.
- **한 번에 한 가지만** 묻거나 시킨다. 답을 받고 다음으로 간다.
- 명령어를 치게 하지 않는다. 명령은 Claude 가 돌린다. 선생님이 할 일은 "어느 화면에서 무엇을 누른다"로 말한다.
- 단계를 시작할 때 "지금 ○단계(전체 5단계) — 무엇을 합니다" 한 줄을 먼저 말한다.
- 단계가 끝날 때마다 `공용/설정상태.json` 에 적는다. 중간에 끊겨도 다음 세션이 거기서 이어 간다.
- 막히면 오류 원문을 그대로 붙이지 말고, 무엇이 안 됐고 선생님이 무엇을 하면 되는지 한두 문장으로 말한다.

## 0. 상태 읽기

`공용/설정상태.json` 을 읽는다. 없으면 만든다.
```json
{"단계": {"1_설치": false, "2_정리": false, "3_반정보": false, "4_온라인채점": false, "5_안내": false},
 "반": [], "온라인채점": {}}
```
(설치 때 백업을 했으면 `"백업"` 칸이 이미 있다 — 지우지 않는다.)
(옛 설치의 `"5_앱설정"` 은 보지 않는다. `"6_안내": true` 는 `"5_안내": true` 와 같다 — 2026-10-28 에 앱 설정 단계를 빼고 6단계를 5단계로 줄였다.)
**모델 확인** — 이 세션 모델이 Sonnet 이 아니면(시스템 안내에 적힌 지금 모델로 판단한다) 단계보다 먼저 말한다: "채팅 입력창 아래 오른쪽의 모델 이름(지금 ○○)을 누르고 「Sonnet 5.5」를 골라 주세요. 한 번 고르면 다음 새 세션도 Sonnet 으로 열립니다. 어려운 판단이 필요한 일은 제가 Opus 에 따로 맡깁니다." 바꿨다고 하면 이어 간다. (루트 CLAUDE.md 「모델 · 에이전트 쓰는 법」)
끝나지 않은 첫 단계부터 한다. "새 반 만들어 줘" · "반 추가"면 아래 「새 반 추가」만 한다(온라인 채점은 한 번 설치하면 모든 반이 같이 쓴다).
**반 폴더를 연 세션(반 세션)에서 불렀으면** — 「시작」 · 「수업 준비」처럼 무엇을 말했든, 이 반이 설정상태 `반정보` 에 없으면 — 3단계를 그 반만 한다 — 1 · 2 · 4 · 5 단계는 학원 공통 세션(루트 폴더) 몫이다. 3단계가 끝나면 "이 반은 끝났습니다. 다른 반 세션에서도 「시작」, 다 끝나면 학원 공통 세션에서 「설치 이어서」라고 해 주세요"라고 하고 멈춘다. 기출 분석(3-3)이 아직 돌고 있으면 "출제경향은 정리되는 대로 알려 드립니다"를 붙인다.

처음이면 이렇게 시작한다:
> "안녕하세요. 지금부터 수업 자료를 만들고 온라인으로 채점하는 환경을 같이 준비하겠습니다. 5단계입니다. 여기저기 있는 수업 자료는 제가 먼저 백업한 뒤 이 폴더로 모으고, 옮기기 전에 꼭 정리안을 보여 드리고 허락을 받겠습니다. 선생님은 몇 가지 질문에 답하고, 제가 화면을 안내하면 누르기만 하시면 됩니다."

**캠퍼스** — 인사 다음, 1단계 전에 한 번만 묻는다(`AskUserQuestion`, 여러 개 고르기): "어느 캠퍼스에서 가르치세요? 여러 캠퍼스를 다니시면 모두 골라 주세요." 선택지 「나성동」 · 「새롬동」 · 「보람동」(그 밖은 직접 입력). 학원 표기는 나성동 → 나성카이젠 · 새롬동 → 새롬카이젠 · 보람동 → 카이젠프리미엄. 답은 `공용/규칙/우리학원.md` 「학원 정보」에 적는다(괄호 안 안내 글은 지운다).
- 한 곳이면 `학원 표기:` · `캠퍼스:` 줄에 그대로 적는다.
- 여러 곳이면 `캠퍼스:` 줄에 고른 캠퍼스를 모두 적고(예: `나성동 · 새롬동`) `학원 표기:` 줄에는 `반마다 다름 (반 CLAUDE.md)` 이라고 적는다. 반마다 어느 캠퍼스인지는 3-0 에서 묻는다.

피드백 문서 · 교재 표지 · 시험지 바닥글의 학원 이름이 여기서 나온다(반 `CLAUDE.md` 의 `학원 표기:` 가 있으면 그것이 먼저). 이미 적혀 있으면 묻지 않는다. 한 곳만 적혀 있는데 선생님이 나중에 "캠퍼스가 하나 더 늘었어"라고 하면 위 「여러 곳」으로 바꾸고, 기존 반마다 원래 캠퍼스를 반 `CLAUDE.md` 에 적는다(반 목록을 보여 주고 맞는지 확인받는다).

**학습 끄기 확인** — 캠퍼스 다음, 1단계 전에(학생 명단을 읽기 전에) 한 번 묻는다(`AskUserQuestion`): "「설정」 → 「개인정보보호」의 「Help improve our AI models」 스위치를 끄셨나요? 학생 이름과 점수가 AI 학습에 쓰이지 않게 하는 설정입니다." 선택지 「껐어」 · 「아직」. 「아직」이면 그 자리에서 끄는 길을 안내하고 「껐어」를 받는다. 받으면 `공용/설정상태.json` 에 `"학습끔": true`. (안내서 1-4 에서 설치 전에 끄게 되어 있다 — 2026-10-28.) Team · Enterprise 계정이면 원래 학습에 쓰이지 않으니 건너뛴다. 옛 설치를 이어 하는 중이라도 설정상태에 `"학습끔"` 이 없으면 다음 단계로 가기 전에 한 번 묻는다.

## 1. 설치 (프로그램 깔기)

1. 먼저 말한다: "필요한 프로그램을 한 번에 깔겠습니다. 윈도우 「예」 창이 두 번쯤 뜨면 「예」를 눌러 주세요. LibreOffice 는 내려받기가 커서 조금 걸립니다."
2. 한 명령으로 깐다 — 있는 것은 건너뛴다. 오래 걸리니 백그라운드로 돌리고 끝나면 결과를 본다:
   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File 공용/설치/프로그램설치.ps1
   ```
   Python(사용자 계정) · Node · LibreOffice · Python 모듈 · 크로미움 · clasp · docx 를 깔고, 마지막에 `== 결과 ==` 아래 항목마다 「있음 · 설치함 · 실패」를 적는다.
   무엇이 있는지만 볼 때는 끝에 `-Check`.
3. `실패` 가 있으면 그 항목만 다시 돌린다(같은 명령 — 있는 것은 건너뛴다). LibreOffice 는 단어 시험지(DOCX → PDF)에만 쓰니, 계속 실패하면 "나중에 다시 깔겠습니다"라고 하고 넘어간다.
   설치 직후에는 PATH 가 지금 창에 반영되지 않는다. 다음 명령 앞에 붙인다:
   `$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')`
   `py` 가 안 잡히면 `$env:LOCALAPPDATA\Programs\Python\Launcher\py.exe` 를 쓴다.
4. 확인 — 샘플 시험지를 만들어 본다. PDF 2개가 나오면 끝이다.
   ```
   py 공용/build/모의고사/build.py 공용/build/모의고사/예시/샘플_3문항.json --out <스크래치 폴더>
   ```
   선생님께 보여 주지 않는다 — 나오면 "프로그램 설치를 마쳤습니다" 한 줄만 말한다. 안 나오면 무엇이 안 됐는지 한두 문장으로 말하고 그 프로그램을 다시 깐다.

## 2. 자료 모으기 · 정리 (여기저기 있는 수업 자료를 이 폴더의 반 폴더로)

선생님 수업 자료는 바탕화면 · 문서 · 다운로드 · 카카오톡 받은 파일 등 여러 곳에 흩어져 있다. 이 폴더(보통 「학원수업」)가 그것들을 모을 한 곳이다.
**자료 위치 묻기 → 백업 → 지금 구조 보여 주기 → 정리안 승인 → 모으기** 순서를 지킨다. 승인 전에는 아무것도 옮기지 않는다. 이 순서는 Claude 가 한다 — 선생님은 위치를 알려 주고 정리안을 승인만 한다.

### 2-1. 자료 위치 묻기
0. **폴더 접근 묻기 (한 번만)** — `공용/설정상태.json` 에 `폴더허용` 이 없으면 `AskUserQuestion` 으로 이 문장 그대로 묻는다: 「나중에 족보닷컴, EXAM4YOU 등의 사이트에서 받은 자료들이나 카톡방에서 받은 자료들을 Claude가 정리할 수 있게 다운로드 폴더와 카카오톡 받은 파일 폴더에 접근하도록 허용하시겠어요?」 선택지 「허용」 · 「안 함」.
   - 허용 → `py 공용/설치/폴더허용.py 허용` — 두 폴더를 이 PC 의 Claude 사용자 설정에 적는다(어느 세션에서든 묻지 않고 읽는다). 「카카오톡 받은 파일 폴더는 못 찾았다」가 나오면 위치를 묻고 `py 공용/설치/폴더허용.py 허용 "<경로>"`.
   - 안 함 → `py 공용/설치/폴더허용.py 안함`. 그 폴더가 필요할 때 앱이 그때 허용 창을 띄운다.
   - 어느 쪽이든 **개인 파일 · 개인 정보로 보이는 파일은 열지 않는다**(자료정리 스킬 규칙).
1. 묻는다: "평소 수업 자료가 어디에 있나요? 채팅 입력창 왼쪽의 「+」를 누르고 「폴더 추가」에서 자료 폴더를 골라 주세요. 폴더가 여러 곳이면 하나씩 되풀이하고, 다 넣으셨으면 '다 추가했어'라고 보내 주세요. 바탕화면의 ○○ 폴더, 다운로드 폴더, 카카오톡 받은 파일처럼 이름만 말씀하셔도 됩니다."
   선생님이 「폴더 추가」로 넣은 폴더는 이 세션의 추가 작업 폴더로 보인다(환경 안내의 작업 폴더 목록). 그 목록과 말로 알려 준 위치를 합쳐 대상으로 삼는다.
2. 선생님이 정확한 위치를 모르면 바탕화면 · 문서 · 다운로드 · `문서\카카오톡 받은 파일` 의 **맨 위 폴더 · 파일 이름만** 보여 주고 고르게 한다. 개인 파일로 보이는 것(사진 · 가족 · 금융 · 설치 파일)은 열어 보지 않는다.
3. 다운로드 · 카카오톡 받은 파일처럼 개인 파일이 섞인 곳은 폴더 전체가 아니라 **수업 자료로 보이는 파일만** 고른다. 이름만 보고 애매하면 목록을 보여 주고 묻는다.
4. 고른 위치 · 파일을 선생님께 한 번 보여 주고 확인받는다: "이것들을 모으겠습니다: 바탕화면\영어수업(폴더) · 다운로드의 출석부 10월.hwp 외 4개. 맞나요?"
5. 이 폴더 안에 이미 선생님 자료가 있으면(설치 때 백업한 것) 그것도 대상이다.

### 2-2. 백업 · 지금 구조
1. **백업** — `py 공용/정리/처음정리.py 백업 "<경로1>" "<경로2>" …` (2-1에서 확인한 폴더 · 파일 전부). 이 폴더 바로 바깥 `학원수업_백업_<날짜>/` 에 출처별로 복사하고, 파일 수를 맞춰 보고, 설정상태 「백업」에 적는다. 공간이 모자라다고 나오면 USB 같은 저장 장치를 꽂아 달라고 한다.
   선생님께 알린다: "원래 자료를 ○○ 에 통째로 백업했습니다(파일 ○개). 앞으로 무엇을 옮겨도 이 백업은 그대로 둡니다."
   그다음 `py 공용/정리/처음정리.py 백업확인` 이 통과해야 다음으로 간다.
2. 모을 자료가 하나도 없으면(아직 자료가 없는 선생님) 2-3 · 2-4 를 건너뛰고 「새 반 추가」로 반을 만든 뒤 2-5(반 세션)로 간다.
3. `py 공용/정리/처음정리.py 목록 "<경로1>" "<경로2>" …` → 위치별 폴더 요약 · 종류별 개수 · 목록 tsv.
4. 이름으로 반 · 종류를 판정한다. 이름으로 모르는 파일은 열어서 본다(자료정리 스킬 3절 방식). **파일이 많으면 `자료분류` 에이전트에 목록째 넘긴다.** 단서: 학교 · 학년 · 교과서 출판사 · 교재 이름 · 수업 시간대 · 학생 이름.
5. 선생님께 **지금 구조**를 짧게 보여 준다 — 위 2~3단계 깊이 폴더 나무와 파일 수, 그리고 "보니까 이런 반이 있는 것 같습니다: 중앙고2(○개) · 서울중3(○개) …".
   반 이름(`<학교 줄임말><학년>`, 예: `중앙고2`)과 **지금 맡고 있는 반인지**를 확인받는다. 지난 학기 · 지난해 반은 `_지난자료/` 로 간다.
   여러 캠퍼스에 같은 학교 · 학년 반이 있으면 폴더 이름 끝에 캠퍼스를 붙인다(예: `중앙고2_나성` · `중앙고2_새롬`).

### 2-3. 정리안 (승인받을 것)
루트 `CLAUDE.md` 「폴더」 구조로 옮기는 안을 만든다. 규칙:

| 지금 있는 것 | 새 자리 |
|---|---|
| 교과서 · 부교재 · 학교 프린트 (남이 만든 원본) | `<반>/학교자료/` · `<반>/학교자료/부교재/` |
| 학교 기출 시험지 | `<반>/학교자료/기출/` |
| 출석부 · 주간보고서 | `<반>/학교자료/출석부/` · `<반>/학교자료/주간보고서/` (여러 반이 한 파일이면 첫 반에 두고 나머지 반 CLAUDE.md 「자료 위치」에 적는다) |
| 선생님이 만든 시험지 · 워크북 · 단어 시험 · 숙제 · 수업 자료 | `<반>/이전자료/` — **원래 하위 폴더 이름을 그대로 유지한다** (선생님이 찾던 대로 찾게) |
| 학평 모의고사 (연도 · 학년 · 월) | `공용/교재/모의고사/<연도_학년_월>/` |
| 여러 반이 같이 쓰는 교재 | `공용/교재/` |
| 지금 맡지 않은 반 · 지난 학기 | `_지난자료/<원래 폴더 이름>/` (안을 다시 나누지 않는다) |
| 반을 알 수 없는 수업 자료 | `_정리대기/확인필요/` — 목록을 보여 주고 묻는다 |
| 개인 파일 · 수업과 관계없는 것 | **그대로 둔다** (옮기지 않는다) |

폴더째 옮길 수 있으면 폴더째 옮긴다(파일마다 쪼개지 않는다). 파일 이름은 바꾸지 않는다.

계획을 `_정리대기/정리기록/<날짜>_처음정리_계획.tsv` 에 쓴다(한 줄에 `원래 경로<TAB>새 경로`. 원래 경로는 절대 경로, 새 경로는 이 폴더 기준 상대 경로). 백업하지 않은 곳은 계획에 넣지 않는다 — 도구도 옮기지 않는다.
그리고 선생님께 **세 가지만** 보여 주고 승인을 받는다:
1. **정리 뒤 모습** — 새 폴더 나무(반 폴더마다 하위 폴더와 파일 수)
2. **무엇이 어디로** — 원래 폴더 단위로 묶은 표 (`원래 폴더 → 새 자리 · 파일 수`). 수십 줄이 넘으면 반별로 묶는다
3. **확인 필요 · 그대로 두는 것** — 반을 모르는 파일, 옮기지 않는 파일 목록

> "이렇게 정리하려고 합니다. 원래 자료는 ○○ 에 백업되어 있고, 옮긴 기록이 남아서 언제든 되돌릴 수 있습니다. 이대로 할까요? 고칠 곳이 있으면 말씀해 주세요."

고칠 곳을 말하면 계획을 고쳐 다시 보여 준다. **"좋아" · "그대로 해" 같은 분명한 승인을 받기 전에는 옮기지 않는다.**

### 2-4. 모으기 (옮기기)
1. 반마다 `_새반_틀/` 을 `<반>/` 으로 복사한다(이미 같은 이름 폴더가 있으면 그 안에 빠진 파일 · 폴더만 채운다).
2. `py 공용/정리/처음정리.py 실행 _정리대기/정리기록/<날짜>_처음정리_계획.tsv`
   - **잠김**이 나오면 그 파일을 연 프로그램(한글 · 뷰어)을 닫아 달라고 하고, 잠긴 줄만 다시 돌린다.
   - **겹침**은 새 자리에 이미 같은 이름이 있다는 뜻이다. 덮어쓰지 않았으니 어떻게 할지 묻는다.
   - 파일 수가 전후로 다르면 멈추고 알린다.
3. 결과를 짧게 보고한다: "○개를 옮겼습니다. 반 폴더 ○개 · 확인 필요 ○개 · 그대로 둔 것 ○개. 마음에 안 들면 「정리 되돌려 줘」라고 하시면 원래대로 돌립니다."
   되돌리기: `py 공용/정리/처음정리.py 되돌리기 _정리대기/정리기록/<…>_처음정리_이동.tsv`
4. `.claude/skills/자료정리/rules.ps1` 「반별 규칙」에 이번에 확인한 교재 이름 · 출판사 · 저자 → 반 규칙을 한 줄씩 넣는다 (예: `if ($n -match 'YBM\(박준언\)') { return '중앙고2\학교자료\부교재' }`). 앞으로 다운로드 폴더 정리가 이 규칙을 쓴다. 고친 뒤 UTF-8 BOM 으로 저장한다(자료정리 스킬 4절 명령).
5. 반마다 텍스트로 바꾼다: `py 공용/build/원본_md변환.py <반>` (hwp · pdf · docx → `학교자료/_텍스트/`)

상태: `"2_정리": true`, `"반": ["중앙고2", …]`.

### 2-5. 반마다 세션 만들기
반 폴더가 정해졌으니 반마다 세션을 하나씩 만든다. 3단계(반 정보)는 반마다 그 반 세션에서 한다 — 이 세션 하나에서 반 다섯 개를 다 하면 대화가 너무 커진다. 선생님은 앞으로도 새 세션을 열고 폴더를 고를 일 없이 반 세션을 계속 쓴다(대화가 길어지면 `.claude/settings.json` 의 `autoCompactWindow` 로 자동 요약된다).
1. 이 세션 이름을 「학원 공통」으로 바꾼다(세션 이름을 바꾸는 도구가 있을 때).
2. 반 폴더(`_` 로 시작하지 않고 `CLAUDE.md` 가 있는 루트 바로 아래 폴더)마다 새 세션을 하나씩 시작한다 — Claude 앱의 세션 시작 도구로, 작업 폴더는 그 반 폴더, 세션 이름은 반 이름, 모델은 Sonnet. 첫 지시는 한도를 쓰지 않게 이것만: "이 세션은 ○○ 반 전용이다. 파일을 읽거나 도구를 쓰지 말고 「○○ 세션 준비됐습니다」 한 줄만 답한다." 이미 그 반 이름의 세션이 있으면 건너뛴다.
3. 다 만들면: "왼쪽 목록에서 이 세션(학원 공통) 아래에 반 이름들이 보입니다. 반 세션을 하나씩 눌러 「시작」이라고 보내 주세요. 다 끝나면 이 세션으로 돌아와 「설치 이어서」라고 해 주세요. 앞으로 그 반 일은 그 반 세션에서, 여러 반에 걸친 일은 이 학원 공통 세션에서 하시면 됩니다."
- 세션 시작 도구가 없거나 앱이 막으면(터미널 · 원격 접속): 3단계를 이 세션에서 반마다 한다. 끝에 "컴퓨터 앞 Claude 앱에서 「반마다 세션 만들어 줘」라고 하시면 반 세션을 만들어 드립니다"라고 한 줄 말한다.
- 선생님이 나중에 「반마다 세션 만들어 줘」라고 하면 2-5 만 한다(3단계 안내는 빼고, 반 정보가 비어 있는 반만 알려 준다).

## 3. 반 정보 (옮긴 자료로 채우고 확인만 받는다)

반마다, 그 반 세션에서 한다(2-5 · 반 세션이 없으면 이 세션에서 반마다). **자료에서 찾을 수 있는 것은 묻지 않고 찾아서 보여 준 뒤 맞는지만 확인받는다.** 자료에 없는 것만 묻는다.
3-1 ~ 3-3 에 쓸 출석부 · 주간보고서 · 기출이 정리한 폴더에 없으면 `<반>/학교자료/_받은자료/` 를 만들어 열어 주고 넣어 달라고 한다(넣으면 종류별로 옮기고 텍스트로 바꾼다).

### 3-0. 과목 · 교재 · 이번 시험
- **과목** — `py 공용/사용기록/보고.py 상태` 의 `과목` 이 비어 있으면 한 번만 묻는다: "가르치시는 과목이 무엇인가요? (영어 · 수학 · 국어 …)" → `py 공용/사용기록/보고.py 과목 <답>`. 「보내」 기록을 과목별로 묶는 데 쓴다. 이미 있으면 묻지 않는다.
- **캠퍼스** — `공용/규칙/우리학원.md` 「캠퍼스」에 둘 이상 적혀 있을 때만 묻는다(`AskUserQuestion`, 선택지는 거기 적힌 캠퍼스): "이 반은 어느 캠퍼스 반인가요?" → 반 `CLAUDE.md` 머리의 `캠퍼스:` · `학원 표기:` 칸을 채운다(예: `캠퍼스: 새롬동 · 학원 표기: 새롬카이젠`). 한 곳이면 묻지 않고 그 줄을 지운다 — `우리학원.md` 의 표기를 쓴다.
- **교재** — `학교자료/` 에 옮긴 교과서 · 부교재 이름으로 반 `CLAUDE.md` 「교재」 표를 채워 보여 준다: "이 반 교재는 ○○(출판사 · 저자)와 ○○ 맞나요? 쏠북 · 족보닷컴처럼 자료 받는 곳이 있으면 알려 주세요." 파일이 없으면 묻는다.
- **이번 시험** — 학교 공지 · 주간보고서 · 수업 계획 파일에서 시험 날짜와 범위를 찾는다. 없으면 "다음 시험 날짜와 시험 범위를 알려 주세요. 모르면 '미정'이라고 하셔도 됩니다." (교과서 몇 과 · 본문만인지 · 모의고사 몇 월 몇 번 · 학교 프린트)
- 반 `CLAUDE.md` 빈칸을 채운다. 모르는 칸은 `[미정]` 으로 두고 「미확보」에 적는다.

### 3-1. 출석부 → 반 명단 · 수업 시간
`_텍스트/` 의 출석부에서 학생 이름과 수업 요일 · 시간을 뽑는다 (파일 이름과 첫 줄 「수업시간」에 요일 · 시간이 있는 경우가 많다). **출석부의 학부모 · 학생 전화번호는 어디에도 옮겨 적지 않는다.** **표로 보여 주고 맞는지 확인받은 뒤** `학생.md` 에 `- **이름**` 줄로, `CLAUDE.md` 머리에 요일 · 시간 · 학생 수를 적는다. 사진 · 스캔이라 글자가 없으면 이름을 직접 받는다.

### 3-2. 주간보고서 → 진도 · 숙제 · 수업 흐름
주간보고서는 표가 풀려 요일 · 반 · 진도 · 숙제 칸이 한 줄씩 나열된 텍스트다 — 날짜 머리줄(예: 「9월 15일 (화)」)과 반 이름 줄(예: 「[중앙고2]」 · 시간대 표)을 기준으로 칸을 다시 맞춘다. 지난 주간보고서에서 **이 반 부분만** 날짜별로 진도 · 숙제 · 단어시험을 뽑아 `수업일지.md` 에 최신이 위로 오게 적는다(줄 끝에 `(주간보고서에서)`). 매번 반복되는 순서(예: 단어시험 → 숙제 확인 → 진도 → 숙제)를 찾아 `CLAUDE.md` 「수업 흐름」에 적는다. 단어시험 형식 · 재시험 기준이 보이면 「단어시험」에 적는다 — 보고서에 없는 기준은 지어내지 않는다.
같은 보고서에서 보이면 「반 편성」(타임별 명단 · 다른 반과 숙제 맞추기)도 채운다.
결과를 짧게 보여 준다: "마지막 기록은 ○월 ○일, 진도는 ○○까지, 숙제는 ○○입니다. 맞나요?"
반 `CLAUDE.md` 의 「단어시험」 · 「온라인 채점」 칸은 여기서 따로 묻지 않는다. 자료에서 보이면 채우고, 비어 있는 칸은 그 작업을 처음 할 때 해당 스킬이 묻는다.
이 기록이 있어야 첫 「수업 준비」부터 지난 수업을 이어 간다.

### 3-3. 기출 → 출제경향 (뒤에서 돌린다)
기출이 있으면 `시험지분석` 스킬의 분석을 **Opus 에이전트에 백그라운드로** 맡기고(Agent 도구 `model: opus`, 결과를 기다리지 않는다) 3-4 와 다음 일을 바로 이어 간다. 선생님께는 "기출 분석을 뒤에서 시작했습니다. 그동안 다음으로 넘어가겠습니다"라고 한 줄만 말한다.
결과가 오면 `분석/출제경향.md` 를 쓰고, 끝에 **학교 규격 파일** `공용/build/학교/<학교>.json` 을 쓴다(`_예시.json` 형식 — 문항 수 · 배점표 · 서답형 여부 · 그 학교가 안 내는 유형). 반 `CLAUDE.md` 「시험 구조」를 채우고 "출제경향이 준비됐습니다. 이제 「실전 모의고사 만들어 줘」라고 하시면 됩니다"라고 알린다. 기출이 1회뿐이면 "한 회만 보고 정한 것"이라고 적어 둔다. 기출이 없으면 「미확보」에 적고 넘어간다.

### 3-4. 이전자료 훑기
`<반>/이전자료/` 에 선생님이 만든 시험지 · 단어 시험이 있으면 형식(문항 수 · 단어 시험 방식 · 자주 쓰는 유형)을 훑어 반 `CLAUDE.md` 「수업 흐름」 · 「단어시험」에 보이는 것만 적는다. 지어내지 않는다.
상태: 그 반을 `"반정보": ["중앙고2", …]` 에 더한다. `"반"` 의 모든 반이 들어가면 `"3_반정보": true`.

## 새 반 추가 ("새 반 만들어 줘" · "반 추가")
1. "어느 학교 몇 학년 반인가요?" → 폴더 이름 `<학교 줄임말><학년>` 을 제안하고 확인받는다. `우리학원.md` 「캠퍼스」가 둘 이상이면 어느 캠퍼스 반인지도 같이 묻는다. 다른 캠퍼스에 같은 이름의 반 폴더가 이미 있으면 끝에 캠퍼스를 붙인다(예: `중앙고2_새롬`). 캠퍼스는 2 에서 복사한 반 `CLAUDE.md` 의 `캠퍼스:` · `학원 표기:` 칸에 적는다(3-0 에서 다시 묻지 않는다).
2. `_새반_틀/` 을 `<반>/` 으로 복사한다.
3. `<반>/학교자료/_받은자료/` 를 만들어 열어 주고 "이 반 출석부 · 주간보고서 · 기출 · 교과서 · 부교재 파일을 넣어 주세요. 다 넣으셨으면 '다 넣었어'라고 말씀해 주세요." 받으면 종류별로 옮기고 텍스트로 바꾼다(2-4의 4 · 5).
4. 2-5 로 그 반 세션을 만들고(이미 있으면 건너뛴다), 3단계는 그 반 세션에서 한다. 세션을 못 만들면 여기서 그 반만 한다.

## 4. 온라인 채점 설치

학생이 휴대폰으로 답을 입력하면 바로 채점되는 장치를 선생님 구글 계정에 만든다. 처음 한 번만 한다.
**시트 · 스크립트 · 학생 점수는 선생님 본인 구글 계정에 만든다.** clasp 는 이 컴퓨터 브라우저에 로그인된 계정 가운데 고른 계정으로 만들기 때문에, 브라우저에 다른 사람(설치를 도와준 사람 등) 계정이 로그인돼 있으면 그 계정에 만들어진다. 그래서 만들기 전에 계정을 확인받는다.
1. `py 공용/온라인채점/설치.py 확인`
2. 로그인이 안 돼 있으면: "브라우저가 열리면 계정 고르기 화면에서 선생님 구글 계정을 골라 주세요. 목록에 없으면 「다른 계정 사용」을 눌러 선생님 계정으로 로그인합니다. 그다음 「허용」을 눌러 주세요." → `py 공용/온라인채점/설치.py 로그인` (시간 제한 10분으로 돌린다)
3. **계정 확인** — 로그인돼 있으면(이미 돼 있었어도) 출력의 메일을 그대로 보여 주고 묻는다: "온라인 채점은 이 구글 계정에 만들어집니다: ○○○@gmail.com. 선생님 계정이 맞나요?"
   - 맞다 → `py 공용/온라인채점/설치.py 계정 <그 메일>`
   - 아니다 → `py 공용/온라인채점/설치.py 로그아웃` → 2로 돌아간다. 계정을 Claude 가 짐작해서 적지 않는다 — 선생님이 맞다고 한 메일만 적는다.
4. "브라우저에 설정 화면을 열겠습니다. 「Google Apps Script API」 글자를 누르면 스위치가 나옵니다. 스위치를 켜 주세요. 켜셨으면 '켰어'라고 말씀해 주세요." → `py 공용/온라인채점/설치.py 설정` (선생님 기본 브라우저에 확인한 계정으로 연다. 호스트의 브라우저 패널은 쓰지 않는다)
5. `py 공용/온라인채점/설치.py 만들기` → 시트 · 스크립트 생성, 코드 올리기, 웹 앱 배포, 주소 기록(README 링크 절 · 설정상태). 확인한 계정과 로그인 계정이 다르면 만들지 않고 멈춘다. API 설정이 꺼져 있다는 출력이면 4로 돌아간다.
6. "편집기를 열겠습니다. 위쪽 함수 목록에서 「설치확인」을 고르고 「실행」을 눌러 주세요. 권한 창이 뜨면 ○○○@gmail.com 을 고르고, '확인되지 않은 앱' 화면이 나오면 「고급」 → 「온라인채점(으)로 이동」 → 「허용」을 눌러 주세요. 선생님 계정에서 선생님이 만든 것이라 안전합니다." → `py 공용/온라인채점/설치.py 편집기`
   선생님이 했다고 하면 설정상태 `"온라인채점": {"권한": true}`.
7. **구글 드라이브 연결** — 다음 단계(샘플 채점키 올리기)에 필요하다. "Claude 앱 왼쪽 아래 선생님 이름 → 「설정」 → 「커넥터」에서 Google Drive 를 연결해 주세요. 목록에 없으면 위쪽 「탐색」에서 Google Drive 를 찾아 연결합니다. 구글 계정은 방금 확인한 ○○○@gmail.com 을 고릅니다." 학생 답 시트를 Claude 가 읽고, 채점키를 올리는 데 쓴다. 연결했다고 하면 드라이브 도구로 「온라인채점」 시트를 찾고, 파일 정보(`get_file_metadata`)의 소유자가 설정상태 `온라인채점.계정` 과 같은지 본다. 시트가 안 나오거나 소유자가 다르면 커넥터가 다른 계정에 연결된 것이다 — 커넥터 연결을 끊고 선생님 계정으로 다시 연결해 달라고 한다. 이 커넥터는 Claude 계정에 붙어 있으니, 이 컴퓨터의 Claude 앱도 선생님 본인 Claude 계정으로 로그인돼 있어야 한다(남의 Claude 계정이면 커넥터도 그 사람 구글 드라이브를 가리킨다).
8. **시험 한 번** — 1단계 샘플 시험지로 채점키를 만들어 올리고 선생님이 직접 내 본다. 반 `학생.md` 에 이름이 하나도 없으면 채점키를 만들 수 없으니 3단계에서 명단을 먼저 채운다.
   - 샘플을 `<반>/시험대비/_설치확인/작업/data.json` 으로 복사(`school` 은 `_예시`)해 `py 공용/build/모의고사/build.py <그 data.json> --out <반>/시험대비/_설치확인/배부` → `py 공용/온라인채점/채점키.py <그 data.json> --id <반>_설치확인 --open`
   - 만든 `공용/온라인채점/채점키/<반>_설치확인_채점키.json` 을 **구글 드라이브 커넥터로 올린다** — 드라이브 도구 `create_file` (title 은 파일 이름 그대로, `contentMimeType` `application/json`, `disableConversionToGoogleType` true, `textContent` 는 파일 내용). 커넥터가 끝내 안 되면 선생님께 그 파일을 drive.google.com 에 끌어다 올려 달라고 한다(위치는 상관없다 — 웹 앱이 이름으로 찾는다)
   - 링크 `<웹 앱 주소>?t=<반>_설치확인` 를 보여 주고: "휴대폰이나 이 컴퓨터 브라우저로 링크를 열고, 이름 목록 맨 끝의 TEST 를 골라 아무 답이나 내 보세요. 점수와 정답이 바로 나오면 성공입니다."
   - 선생님이 됐다고 하면 끝. `"4_온라인채점": true`.

**다른 계정에 이미 만들어졌을 때** (`확인` 의 "만든 계정"이 선생님 계정이 아니거나, 선생님이 시트가 남의 드라이브에 있다고 할 때): `py 공용/온라인채점/설치.py 처음부터` → 이 컴퓨터의 연결과 주소 기록을 지우고 로그아웃한다 → 2부터 다시 한다. 그 계정에 생긴 「온라인채점」 시트 · 스크립트는 Claude 가 지우지 않는다 — 그 계정 주인에게 드라이브에서 지워 달라고 전한다. 그 주소로 이미 학생 링크를 보냈다면 새 주소로 다시 보내야 한다고 알린다.

## 5. 쓰는 법 안내 (마지막)

짧게 보여 주고 끝낸다.
- 이렇게 말하면 된다: 「수업 준비」 · 「오늘 수업 정리」 · 「단어 시험지 만들어 줘」 · 「실전 모의고사 1회 만들어 줘」 · 「온라인 배포해 줘」 · 「제출 확인해 줘」 · 「약점 보완 자료 만들어 줘」 · 「수업 계획표 짜 줘」 · 「다운로드 정리해」
- 반 일은 왼쪽 목록의 그 반 세션에서, 여러 반에 걸친 일은 학원 공통 세션에서 한다. 대화가 길어지면 알아서 요약되니 새 세션을 열지 않아도 된다.
- 같은 작업을 두 번째 하면 Claude 가 "스킬로 만들어 둘까요?"라고 묻는다. 스킬은 작업 설명서다. 만들어 두면 다음부터 한마디로 같은 방식으로 만든다.
- Pro 구독이면 사용 한도가 있다. 시험 대비 자료는 2~3주에 나눠 만들고, 시험 전 이틀에 몰지 않는다.
- 시험 날짜가 있으면 남은 주를 세어 "이번 주에 할 일"을 하나 제안한다.
- **사용 기록** — 쓰는 동안 작업 기록(규칙 보완 · 수정 · 생성한 파일 이름)과 오류가 이 컴퓨터(`공용/사용기록/`)에 쌓인다. 입력한 채팅과 Claude 답은 기록하지 않는다. 「수업 준비」 때 일주일에 한 번 제작자에게 보낼지 묻고, 「보내」를 골라야만 간다(「거부」면 다시 묻지 않는다). 그때 새로 만든 자료(data.json)와 새로 만들거나 수정한 스킬도 같이 간다. 플러그인 보완과 업데이트에만 쓴다. 학생 이름 · 메일 · 전화번호는 거르고, 피드백 · 채점 결과처럼 학생 답이 든 파일은 보내지 않는다. `py 공용/사용기록/보고.py 상태` 의 `설치ID` 를 선생님께 보여 주고 "이 8자를 제작자에게 카톡으로 알려 주세요 — 어느 컴퓨터에서 온 기록인지 구별하는 표시입니다"라고 한다.
상태: `"5_안내": true`, `"설치끝": "<지금 시각 YYYY-MM-DD HH:MM:SS>"` (이 시각 전 사용 기록은 오류만 제작자에게 간다). 이후 세션부터는 이 스킬을 부르지 않는다.

## 하지 말 것
- 선생님 대신 구글 로그인 · 권한 허용 · 결제 화면을 누르지 않는다. 화면을 열어 주고 무엇을 누를지만 말한다.
- 출석부 · 주간보고서 · 기출 원본 파일을 고치지 않는다.
- 백업 없이 선생님 자료를 옮기지 않는다. 정리안 승인 없이 옮기지 않는다. 지우지 않는다(옮긴 뒤 비어 버린 폴더만 정리 도구가 지운다). 백업 폴더는 건드리지 않는다.
- 다른 위치에서는 백업하고 승인받은 수업 자료만 옮긴다. 바탕화면 · 다운로드 같은 상위 폴더 자체와 개인 파일은 건드리지 않는다.
- 학생 이름 · 점수를 이 컴퓨터와 선생님 구글 계정 밖으로 보내지 않는다.
- 선생님이 맞다고 확인하지 않은 구글 계정에 온라인 채점을 만들지 않는다. 브라우저 · clasp 에 로그인된 계정이 선생님 것이라고 짐작하지 않는다.
- 재시험 기준 · 커트라인 · 단어시험 형식을 지어내지 않는다.
