# 처음시작

사용자는 **Claude Code 를 처음 쓰는 선생님**이다. 아래를 지킨다.
- **한 번에 한 가지만** 묻거나 시킨다. 답을 받고 다음으로 간다.
- 명령어를 치게 하지 않는다. 명령은 Claude 가 돌린다. 선생님이 할 일은 "어느 화면에서 무엇을 누른다"로 말한다.
- 단계를 시작할 때 "지금 ○단계(전체 6단계) — 무엇을 합니다" 한 줄을 먼저 말한다.
- 단계가 끝날 때마다 `공용/설정상태.json` 에 적는다. 중간에 끊겨도 다음 세션이 거기서 이어 간다.
- 막히면 오류 원문을 그대로 붙이지 말고, 무엇이 안 됐고 선생님이 무엇을 하면 되는지 한두 문장으로 말한다.

## 0. 상태 읽기

`공용/설정상태.json` 을 읽는다. 없으면 만든다.
```json
{"단계": {"1_설치": false, "2_반": false, "3_자료": false, "4_온라인채점": false, "5_앱설정": false, "6_안내": false},
 "반": [], "온라인채점": {}}
```
끝나지 않은 첫 단계부터 한다. "새 반 만들어 줘" · "반 추가"면 2 · 3단계만 다시 한다(온라인 채점은 한 번 설치하면 모든 반이 같이 쓴다).

처음이면 이렇게 시작한다:
> "안녕하세요. 지금부터 수업 자료를 만들고 온라인으로 채점하는 환경을 같이 준비하겠습니다. 6단계이고 1시간 안팎 걸립니다. 선생님은 몇 가지 질문에 답하고, 제가 화면을 안내하면 누르기만 하시면 됩니다."

## 1. 설치 (프로그램 깔기)

1. 있는지 본다: `py --version` · `node --version` · `clasp --version`
2. 없는 것만 설치한다. 설치 전에 "설치 창이 뜨면 「예」를 눌러 주세요"라고 말한다.
   ```
   winget install -e --id Python.Python.3.12 --accept-source-agreements --accept-package-agreements
   winget install -e --id OpenJS.NodeJS.LTS --accept-source-agreements --accept-package-agreements
   ```
   설치 직후에는 PATH 가 지금 창에 반영되지 않는다. 다음 명령 앞에 붙인다:
   `$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')`
   `py` 가 안 잡히면 `$env:LOCALAPPDATA\Programs\Python\Launcher\py.exe` 를 쓴다.
3. 모듈 · 브라우저 · clasp · 단어시험지용 도구:
   ```
   py -m pip install pymupdf playwright pdfplumber openpyxl python-docx olefile
   py -m playwright install chromium
   npm install -g @google/clasp docx
   [Environment]::SetEnvironmentVariable('NODE_PATH', (npm root -g), 'User'); $env:NODE_PATH = (npm root -g)
   winget install -e --id TheDocumentFoundation.LibreOffice --accept-source-agreements --accept-package-agreements
   ```
   LibreOffice 는 단어 시험지(DOCX → PDF)에만 쓴다. 내려받기가 커서 5분쯤 걸린다고 미리 말한다.
4. 확인 — 샘플 시험지를 만들어 본다. PDF 2개가 나오면 끝이다.
   ```
   py 공용/build/모의고사/build.py 공용/build/모의고사/예시/샘플_3문항.json --out <스크래치 폴더>
   ```
   나온 PDF 를 브라우저 패널에 띄워 "이런 시험지가 만들어집니다"라고 보여 준다.

## 2. 반 만들기 (질문 셋)

하나씩 묻는다.
1. **반** — "어느 학교 몇 학년 반인가요? (예: 중앙고 2학년)" → 폴더 이름 `<학교 줄임말><학년>` (예: `중앙고2`)을 제안하고 확인받는다.
2. **교재 이름** — "이 반에서 쓰는 교과서(출판사 · 저자)와 부교재 이름을 알려 주세요. 쏠북 · 족보닷컴 · 이그잼포유처럼 자료를 받는 곳이 있으면 같이 알려 주세요."
   - 반 `CLAUDE.md` 「교재」 표에 적는다.
   - `.claude/skills/자료정리/rules.ps1` 의 「반별 규칙」 자리에 교재 이름 · 출판사 · 저자로 가는 규칙을 한 줄씩 넣는다 (예: `if ($n -match 'YBM\(박준언\)') { return '중앙고2\학교자료\부교재' }`). 다운로드 폴더 정리가 이 규칙으로 반을 가른다. 고친 뒤 UTF-8 BOM 으로 저장한다(자료정리 스킬 4절 명령).
3. **이번 시험** — "다음 시험 날짜와 시험 범위를 알려 주세요. 모르면 '미정'이라고 하셔도 됩니다." (교과서 몇 과 · 본문만인지 · 모의고사 몇 월 몇 번 · 학교 프린트)

`_새반_틀/` 을 `<반>/` 으로 복사하고 반 `CLAUDE.md` 빈칸을 채운다. 모르는 칸은 `[미정]` 으로 두고 「미확보」에 적는다.
상태: `"2_반": true`, `"반": ["중앙고2"]`.

## 3. 자료 받기 (파일 넣기)

`<반>/학교자료/_받은자료/` 폴더를 만들고 탐색기로 열어 준다(호스트의 파일 열기 도구가 있으면 그것으로). 그리고:
> "이 폴더에 아래 파일을 끌어다 넣어 주세요. 없는 것은 건너뛰셔도 됩니다. 다 넣으셨으면 '다 넣었어'라고 말씀해 주세요.
>  ① 이번 달 출석부 ② 지난 주간보고서(있는 만큼) ③ 학교 기출 시험지(사진도 됩니다) ④ 교과서 본문 · 부교재 파일"

받으면 파일마다 종류를 판정해 옮긴다 (이름 · 첫 쪽 텍스트로. 모르면 묻는다):
- 출석부 → `학교자료/출석부/` · 주간보고서 → `학교자료/주간보고서/` · 기출 → `학교자료/기출/` · 교과서 · 부교재 → `학교자료/` · `학교자료/부교재/`

그다음 텍스트로 바꾼다: `py 공용/build/원본_md변환.py <반>` (hwp · pdf · docx → `학교자료/_텍스트/`)

### 3-1. 출석부 → 반 명단 · 수업 시간
`_텍스트/` 의 출석부에서 학생 이름과 수업 요일 · 시간을 뽑는다 (파일 이름과 첫 줄 「수업시간」에 요일 · 시간이 있는 경우가 많다). **출석부의 학부모 · 학생 전화번호는 어디에도 옮겨 적지 않는다.** **표로 보여 주고 맞는지 확인받은 뒤** `학생.md` 에 `- **이름**` 줄로, `CLAUDE.md` 머리에 요일 · 시간 · 학생 수를 적는다. 사진 · 스캔이라 글자가 없으면 이름을 직접 받는다.

### 3-2. 주간보고서 → 진도 · 숙제 · 수업 흐름
주간보고서는 표가 풀려 요일 · 반 · 진도 · 숙제 칸이 한 줄씩 나열된 텍스트다 — 날짜 머리줄(예: 「9월 15일 (화)」)과 반 이름 줄(예: 「[중앙고2]」 · 시간대 표)을 기준으로 칸을 다시 맞춘다. 지난 주간보고서에서 **이 반 부분만** 날짜별로 진도 · 숙제 · 단어시험을 뽑아 `수업일지.md` 에 최신이 위로 오게 적는다(줄 끝에 `(주간보고서에서)`). 매번 반복되는 순서(예: 단어시험 → 숙제 확인 → 진도 → 숙제)를 찾아 `CLAUDE.md` 「수업 흐름」에 적는다. 단어시험 형식 · 재시험 기준이 보이면 「단어시험」에 적는다 — 보고서에 없는 기준은 지어내지 않는다.
결과를 짧게 보여 준다: "마지막 기록은 ○월 ○일, 진도는 ○○까지, 숙제는 ○○입니다. 맞나요?"
이 기록이 있어야 첫 「수업 준비」부터 지난 수업을 이어 간다.

### 3-3. 기출 → 출제경향
기출이 있으면 `시험지분석` 스킬로 `분석/출제경향.md` 를 만들고, 끝에 **학교 규격 파일** `공용/build/학교/<학교>.json` 을 쓴다(`_예시.json` 형식 — 문항 수 · 배점표 · 서답형 여부 · 그 학교가 안 내는 유형). 반 `CLAUDE.md` 「시험 구조」를 채운다. 기출이 1회뿐이면 "한 회만 보고 정한 것"이라고 적어 둔다. 기출이 없으면 「미확보」에 적고 넘어간다.
상태: `"3_자료": true`.

## 4. 온라인 채점 설치

학생이 휴대폰으로 답을 입력하면 바로 채점되는 장치를 선생님 구글 계정에 만든다. 처음 한 번만 한다.
1. `py 공용/온라인채점/설치.py 확인`
2. 로그인이 안 돼 있으면: "브라우저가 열리면 학원 일에 쓰는 구글 계정으로 로그인하고 「허용」을 눌러 주세요." → `py 공용/온라인채점/설치.py 로그인` (시간 제한 10분으로 돌린다)
3. "브라우저에 설정 화면을 열겠습니다. 「Google Apps Script API」 옆 스위치를 켜 주세요. 켜셨으면 '켰어'라고 말씀해 주세요." → https://script.google.com/home/usersettings 를 연다(호스트의 브라우저 패널이 아니라 선생님 기본 브라우저 — 구글 로그인이 거기 있다. `Start-Process <주소>`)
4. `py 공용/온라인채점/설치.py 만들기` → 시트 · 스크립트 생성, 코드 올리기, 웹 앱 배포, 주소 기록(README 링크 절 · 설정상태). API 설정이 꺼져 있다는 출력이면 3으로 돌아간다.
5. "편집기를 열겠습니다. 위쪽 함수 목록에서 「설치확인」을 고르고 「실행」을 눌러 주세요. 권한 창이 뜨면 계정을 고르고, '확인되지 않은 앱' 화면이 나오면 「고급」 → 「온라인채점(으)로 이동」 → 「허용」을 눌러 주세요. 선생님 계정에서 선생님이 만든 것이라 안전합니다." → `py 공용/온라인채점/설치.py 편집기`
   선생님이 했다고 하면 설정상태 `"온라인채점": {"권한": true}`.
6. **시험 한 번** — 1단계 샘플 시험지로 채점키를 만들어 올리고 선생님이 직접 내 본다. 반 `학생.md` 에 이름이 하나도 없으면 채점키를 만들 수 없으니 3단계에서 명단을 먼저 채운다.
   - 샘플을 `<반>/시험대비/_설치확인/작업/data.json` 으로 복사(`school` 은 `_예시`)해 `py 공용/build/모의고사/build.py <그 data.json> --out <반>/시험대비/_설치확인/배부` → `py 공용/온라인채점/채점키.py <그 data.json> --id <반>_설치확인 --open`
   - 만든 `공용/온라인채점/채점키/<반>_설치확인_채점키.json` 을 **구글 드라이브 커넥터로 올린다** — 드라이브 도구 `create_file` (title 은 파일 이름 그대로, `contentMimeType` `application/json`, `disableConversionToGoogleType` true, `textContent` 는 파일 내용). 커넥터가 아직 없으면 5단계(커넥터 연결)를 먼저 하고 돌아온다. 커넥터가 끝내 안 되면 선생님께 그 파일을 drive.google.com 에 끌어다 올려 달라고 한다(위치는 상관없다 — 웹 앱이 이름으로 찾는다)
   - 링크 `<웹 앱 주소>?t=<반>_설치확인` 를 보여 주고: "휴대폰이나 이 컴퓨터 브라우저로 링크를 열고, 이름 목록 맨 끝의 TEST 를 골라 아무 답이나 내 보세요. 점수와 정답이 바로 나오면 성공입니다."
   - 선생님이 됐다고 하면 끝. `"4_온라인채점": true`.

## 5. Claude 앱 설정 (두 가지)

1. **구글 드라이브 연결** — "Claude 앱 왼쪽 아래 이름 → 「설정」 → 「커넥터」에서 Google Drive 를 연결해 주세요. 4단계에서 만든 계정과 같은 계정입니다." 학생 답 시트를 Claude 가 읽고, 채점키를 올리는 데 쓴다. 연결했다고 하면 드라이브 도구로 「온라인채점」 시트가 검색되는지 확인한다.
2. **학습 사용 끄기** — "「설정」 → 「개인정보」에서 「Claude 개선 돕기」를 꺼 주세요. 학생 이름과 점수가 AI 학습에 쓰이지 않게 하는 설정입니다." (Team · Enterprise 계정이면 원래 학습에 쓰이지 않으니 건너뛴다)
상태: `"5_앱설정": true`.

## 6. 쓰는 법 안내 (마지막)

짧게 보여 주고 끝낸다.
- 이렇게 말하면 된다: 「수업 준비」 · 「오늘 수업 정리」 · 「단어 시험지 만들어 줘」 · 「실전 모의고사 1회 만들어 줘」 · 「온라인 배포해 줘」 · 「제출 확인해 줘」 · 「약점 보완 자료 만들어 줘」 · 「수업 계획표 짜 줘」 · 「다운로드 정리해」
- 반 하나만 작업할 때는 Code 탭에서 그 반 폴더를 열고 시작하면 그 반 규칙만 올라온다.
- 같은 작업을 두 번째 하면 Claude 가 "스킬로 만들어 둘까요?"라고 묻는다. 스킬은 작업 설명서다. 만들어 두면 다음부터 한마디로 같은 방식으로 만든다.
- Pro 구독이면 사용 한도가 있다. 시험 대비 자료는 2~3주에 나눠 만들고, 시험 전 이틀에 몰지 않는다.
- 시험 날짜가 있으면 남은 주를 세어 "이번 주에 할 일"을 하나 제안한다.
상태: `"6_안내": true`. 이후 세션부터는 이 스킬을 부르지 않는다.

## 하지 말 것
- 선생님 대신 구글 로그인 · 권한 허용 · 결제 화면을 누르지 않는다. 화면을 열어 주고 무엇을 누를지만 말한다.
- 출석부 · 주간보고서 · 기출 원본 파일을 고치지 않는다.
- 학생 이름 · 점수를 이 컴퓨터와 선생님 구글 계정 밖으로 보내지 않는다.
- 재시험 기준 · 커트라인 · 단어시험 형식을 지어내지 않는다.
