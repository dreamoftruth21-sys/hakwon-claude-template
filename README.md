# 학원 수업 준비 · Claude Code 템플릿

영어 내신 수업 자료를 Claude 로 만들고, 학생 답을 휴대폰으로 받아 바로 채점하는 작업 공간입니다.
실전 모의고사 → 온라인 답안 · 즉시 채점 → 학생별 약점 분석 → 약점 보완 자료 · 약점 확인 시험까지 한 줄기로 돌아갑니다.

## 설치 (선생님이 하는 일은 이것뿐입니다)

1. **Claude 데스크톱 앱**을 설치하고 로그인합니다 — https://claude.com/download
2. 앱 왼쪽 위 **Code** 탭 → **폴더 선택**에서 **평소 수업 자료가 들어 있는 폴더**를 엽니다.
   자료가 여러 곳에 흩어져 있으면 가장 많이 들어 있는 폴더를 엽니다. 나머지 위치는 Claude 가 나중에 묻습니다.
   수업 자료가 아직 없으면 새 폴더 `학원 수업 준비` 를 만들어 엽니다.
3. 아래 한 줄을 그대로 복사해 붙여넣고 보냅니다.

```
https://github.com/dreamoftruth21-sys/hakwon-claude-template 여기 있는 것 이 폴더에 설치해줘
```

4. Claude 가 먼저 폴더 전체를 백업하고, 설치가 끝나면 폴더를 다시 열라고 안내합니다. 다시 열면 그다음부터는 Claude 가 한 단계씩 안내하고 필요한 것을 묻습니다.

## Claude 가 설치할 때 할 일 (Claude 용 안내)

**1. 백업 먼저 — 폴더에 파일이 하나라도 있으면 아무것도 바꾸기 전에 한다.**
- 열린 폴더의 파일 수 · 전체 크기와 그 드라이브의 남은 공간을 잰다 (`Get-ChildItem -Recurse -File -Force` · `Get-PSDrive`). 남은 공간이 폴더 크기보다 작으면 멈추고, USB 같은 다른 저장 장치를 꽂아 달라고 한 뒤 그곳에 백업한다.
- 같은 위치(폴더 바로 위)에 `<폴더 이름>_백업_<YYYYMMDD>` 로 통째로 복사한다: `robocopy "<폴더>" "<백업>" /E /COPY:DAT /R:1 /W:1 /NFL /NDL /NP` (종료 코드 0~7 이 성공).
- 백업 쪽 파일 수가 원래 폴더와 같은지 확인한다. 다르면 멈추고 알린다.
- 선생님께 한 줄로 알린다: "원래 자료를 ○○ 에 통째로 백업했습니다(파일 ○개). 앞으로 무엇을 옮겨도 이 백업은 그대로 둡니다."
- 폴더가 OneDrive · 구글 드라이브 동기화 폴더 안이면 백업도 같이 동기화된다고 알린다.
- 백업 경로 · 파일 수 · 날짜는 압축을 푼 뒤 `공용/설정상태.json` 에 `"백업": {"경로": …, "파일수": …, "날짜": …}` 로 적는다.

**2. 템플릿 풀기**
- 이 저장소의 zip(`https://github.com/dreamoftruth21-sys/hakwon-claude-template/archive/refs/heads/main.zip`)을 PowerShell `Invoke-WebRequest` 로 스크래치 폴더에 내려받아 압축을 풀고, `hakwon-claude-template-main/` 안의 내용을 열린 폴더 바로 아래로 옮긴다. git 은 쓰지 않는다.
- 선생님 파일 · 폴더와 이름이 같은 것(`CLAUDE.md` · `README.md` · `공용` · `.claude` 등)이 있으면 덮어쓰지 말고 멈춰서 알린다.
- **선생님 자료는 이 단계에서 옮기지 않는다.** 정리는 처음시작 스킬 2단계에서 구조를 보여 주고 승인을 받은 뒤에 한다.

**3.** 다 풀면 "폴더를 다시 열어 주세요(Code 탭 → 같은 폴더 선택). 다시 열고 「처음 시작」이라고 보내 주세요." 라고 말하고 멈춘다. 다시 열면 루트 `CLAUDE.md` 가 `처음시작` 스킬을 시작한다.

## 들어 있는 것

- `CLAUDE.md` — 전체 작업 규칙
- `.claude/skills/` — 처음시작 · 수업준비 · 수업정리 · 수업계획 · 단어시험지 · 시험지분석 · 모의고사출제 · 자체점검 · 온라인배포 · 서술형채점 · 약점보완 · 교재만들기 · 숙제합본 · 쉬운말번역 · 내신피드백 · 자료정리 · 갱신
- `공용/build/` — 시험지 · 단어장 · 약점 보완 자료 등을 PDF 로 만드는 빌더 (점검에 걸리면 PDF 를 내보내지 않는다)
- `공용/온라인채점/` — 휴대폰 답안 · 즉시 채점 (구글 시트 + Apps Script, 선생님 구글 계정에 설치)
- `공용/정리/` — 처음 설치 때 기존 수업 폴더를 반 폴더 구조로 옮기는 도구 (기록 · 되돌리기)

학생 자료 · 교과서 지문은 들어 있지 않습니다. 선생님 반 자료는 선생님 컴퓨터와 구글 계정에만 저장됩니다.
