# 겹침 대조 — 이미 푼 문항과 같은 곳을 묻는지 (참고용)

```
py 공용/build/겹침대조/겹침대조.py <모의고사 data.json>
```
반 폴더 세션이면 `py ../공용/build/겹침대조/겹침대조.py …`

**막지 않는다.** 같은 지문을 다시 쓰는 것은 당연하고, 같은 곳(같은 빈칸·같은 밑줄·같은 보기)을 다시 묻는 것도 금지가 아니다 —
복습용으로 일부러 다시 물을 수 있다. 겹친 곳을 보여 주면 만드는 쪽이 의도했는지 판단한다. 종료 코드는 늘 0이다.

## 무엇과 대조하나
data.json 위의 `작업/` 폴더 전체를 훑는다. 설정 파일은 없다.

| 대상 | 무엇을 꺼내나 |
|---|---|
| 다른 회차 모의고사 (`questions` 가 있는 json — 공용 모의고사 빌더 형식) | 선택지 · &lt;보기&gt; · 모범답안 |
| 워크북 · 변형문제 등의 .py · .json | 영어 문자열 7~34단어 (문항 요소로 본다) |

- 지문으로 보고 빼는 것: 35단어 이상 문자열, 파일 이름이 body · src · light · ext · all · raw · text · 원문 · 본문인 파일, 모의고사의 지문. 이 "지문 말뭉치"와 5단어 연쇄가 절반 넘게 겹치는 문자열도 지문 인용으로 보고 뺀다
- 빼는 폴더·파일: 대상 data.json 자신, 대상과 같은 폴더의 빌드 파일(mk.py · src.json), 이름이 `_` 로 시작하는 폴더(이전판 · 렌더), `__pycache__`
- 대상 쪽은 선택지 · &lt;보기&gt; 줄 · 모범답안만 본다. 지문은 보지 않는다
- 4단어 연쇄가 45% 이상 겹치면 적는다
