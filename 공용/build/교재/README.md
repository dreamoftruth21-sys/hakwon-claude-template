# 교재 빌더 — 시험대비 교재 한 권

여러 자료(원본 교재 쪽 · 직접 만든 PDF · 직접 출제 문제)를 **푸는 순서대로** 한 권으로 묶는다.
표지 → 차례(한 쪽) → 단계마다 속표지(양면 앞면) → 내용 → 「정답과 해설」 속표지 → 단계 순서대로 정답. `_답지.pdf`(정답 부분만, 쪽번호는 책과 같다)도 같이 만든다.

```
py 공용/build/교재/build.py <교재.json> [--skip-prep]
```

- `--skip-prep` — `_parts/` 를 다시 만들지 않고 묶기만 (prep · 직접 출제 조판을 건너뛴다)
- 구성은 반마다 새로 정한다 (`교재만들기` 스킬). 세종예고2 사례: `세종예고2/시험대비/2026-2학기-기말/작업/교재1권/교재.json` · `공용/규칙/교재구성.md`
- 첫 쪽 삼각형 표식은 찍지 않는다 (제본하는 교재 — 10/15 강사 지시)

| 파일 | 하는 일 |
|---|---|
| `build.py` | 쪽 배치 · 표지 · 차례 · 속표지 · 원본 쪽 넣기(범위 밖 지우기 · 원래 쪽번호 가리기) · 쪽번호 · 쪽번호표 · 수업계획 숙제 표 |
| `render.py` | 직접 출제 `data/*.json` → `_parts/sec_<key>.pdf` · `ans_<key>.pdf` |
| `원본정답.py` | 다른 교재에서 가져온 정답 쪽에서 교재에 넣지 않은 활동의 답을 지운다 (출판사 형식별) |

## 폴더

`교재.json` 이 있는 폴더가 **작업 폴더**다. 한 폴더에 여러 권을 두려면 `교재1권.json` · `교재2권.json` 처럼 이름을 달리한다 — 쪽번호표가 `_parts/쪽_교재1권.json` 으로 따로 생긴다 (한솔고2 10/16). `_parts/`(만든 부분 · 쪽번호표 `쪽.json`)가 여기에 생기고, `prep` 명령과 `data` 경로는 이 폴더 기준이다.
그 밖의 경로(`out` · `source_base` · `plan.md`)는 **학원 폴더 기준**이다.

## 교재.json

```jsonc
{
 "title": "세종예고2 · 2026학년도 2학기 기말 · 영어Ⅱ 2과 교재 1권",   // 속표지 · 직접 출제 쪽 머리글
 "short": "세종예고2",                                               // 시험지형 머리 상자 둘째 줄 앞
 "out": "<반>/시험대비/<시험>/배부/<파일>.pdf",                       // 답지는 이름 끝에 _답지
 "cover": {"brand": ["나성카이젠", "영어"], "school": ["줄1", "줄2"], "eyebrow": "교과서 · 과 · 권",
           "title": "학교 학년 (크게)", "title2": "무엇 (둘째 줄)", "subtitle": "과 제목 (영어 기울임)"},
 "source_base": "<반>/학교자료/부교재",
 "sources": {                                                         // 원본 교재 — 키는 아래 src 에서 쓴다
   "sol": {"file": "….pdf", "kind": "쏠북워크북", "answer_from": 77}   // kind · answer_from 은 정답 쪽을 지울 때만
 },
 "hide": {"regex": "World Link|…", "marker": "[World Link]"},        // 본문 쪽 글자에 regex 가 걸리면 marker 줄부터 쪽 끝까지 지운다 (못 찾으면 멈춤) · marker 는 목록도 된다 ["[Read Culture]", "[Read More]"]
 "prep": [["py", "../단어장/build.py", "--part"], ["py", "지문정리.py"]],   // _parts 를 만드는 그 반 스크립트 ("py" = 이 파이썬)
 "data": ["data/*.json"],                                             // 직접 출제 (render.py)
 "stages": [
  {"label": "①", "name": "본문 해석", "desc": "속표지 한 줄", "toc": "(차례 머리, 생략하면 '① 본문 해석')",
   "items": [
    {"title": "차례 제목", "sub": "부제", "key": "쪽번호표 이름",
     "src": [["sol", "1-3,5-7"], ["part", "sec_P.pdf"]],              // 원본 쪽(인쇄 쪽 아닌 PDF 쪽) 또는 _parts 파일
                                                                      // _parts 파일 일부: ["part", "sec_8.pdf", ["^2회$", "^3회$"]] — 시작 · 끝 쪽 첫머리 정규식(null = 처음 · 끝까지). 두 자료를 숙제 순서대로 번갈아 묶을 때
     "split": [["빈칸", 0], ["해석연습", 5], ["3회", "^3회$"]]}         // 숙제로 나눌 구간: 항목 안 몇째 쪽(0부터) 또는 그 쪽 첫머리 정규식
   ]}
 ],
 "answers": [
  {"stage": "①", "items": [
    {"title": "속표지 · 차례에 나올 이름", "src": [["e4u", "76-77"]],
     "clean": {"keep": ["워크북2", "워크북4"]}}                         // 원본 정답 쪽에서 남길 활동 (아래)
  ]}
 ],
 "plan": {                                                            // 수업계획 문서의 한 절을 쪽번호표로 다시 쓴다 (없으면 생략)
  "md": "<반>/시험대비/<시험>/수업계획.md", "from": "## 4-1.", "to": "## 5.",
  "text": ["## 4-1. …", "교재({전체}쪽, 정답 {답}쪽부터)", "| 낼 날 | 숙제 | 양 |", "|---|---|---|", "{rows}"],
  "rows": [["10/20 화", "빈칸 연습 {빈칸}", "약 40분"]],             // {키} = 쪽번호표 (items 의 key · split 이름 · 답 · 전체)
  "replace": [["정규식", "바꿀 글 {키}"]]
 },
 "after": [["py", "../수업계획표/build.py"]]                          // 다 묶은 뒤 돌릴 명령
}
```

## 직접 출제 (render.py)

`data/<파일>.json` = `{"sections": [{"key", "title", "intro", "parts": [{"title", "note", "problems": [...]}]}]}`.
문항 종류(mcq · judge · write · bundle · vocab · **select**)와 표기(`{ⓐ|x}` · `[05]` · `_____` · `**굵게**`)는 세종예고2 `작업/교재1권/출제지침.md` 「JSON 형식」. 출제 규칙은 반마다 그 반 출제경향으로 따로 쓴다.

`select` (「있는 대로」 고르기, 한솔고2 10/16) = `q` · `passage`(선택) · `items`: `[{"k": "a", "t": "보기 문장", "ok": true, "why": "근거(답지)"}]` · `answer`: `"a, d, e"` (문자열). 학생 쪽: 보기 상자 + 판정표(기호 · O/X · 근거 문장 번호 / 틀린 낱말) + 답 칸. 학생 대화형은 `t` 를 「학생 A: …」로 쓰고 `k` 도 같은 대문자로. 문항에 `"box_first": true` 를 주면 상자(주어진 글)가 지문 앞에 온다 (순서배열).

part 에 `"start": n` 을 주면 문항 번호를 n 부터 매긴다 (한 세트를 날짜별로 나눠 실을 때).

섹션 판형:

| 칸 | 뜻 |
|---|---|
| `"layout": "exam"` + `"exam_sub"` | 시험지처럼 두 단 · 회(part)마다 새 쪽 · 머리 상자(제목 · `short · exam_sub · N문항` · 이름 · 점수). 답지도 회마다 새 쪽, 맨 위 정답 번호표 → 아래 해설 |
| `"layout": "compact"` | 판정표 칸을 줄여 한 쪽에 두 문제 |
| `"newpage": true` | part 마다 새 쪽 |

지문(`.psg`) · 상자는 단 · 쪽 경계에서 자르지 않는다. 선택지가 번호 그 자체(`["①", …]` — 밑줄 ①~⑤ 고르기)면 번호를 한 번만 찍는다.

## 원본 정답 지우기 (원본정답.py)

| kind | 활동을 가르는 머리 | clean |
|---|---|---|
| `이그잼포유워크북` | `워크북 N` · `본문 외 지문`(→ WL) | `{"keep": ["워크북2", …]}` |
| `쏠북워크북` | `어휘 선택 12p` 같은 활동 머리 + 문항 `01 ` | `{"keep": [활동…], "max_item": {"*": 5, "문장삽입": 4}}` — 문항 번호 상한 (World Link 문항 빼기). 정답 쪽의 `[Read Culture]` · `[Read More]` · `[World Link]` 표시 뒤는 다음 활동 머리까지 지운다 (번호가 01부터 다시 시작하는 활동). 앞 해설 덩어리 끝에 붙은 활동 머리도 알아본다 (10/16 세종예고1) |
| `이그잼포유GBU` | `Pattern 1 Exercise 9` · Warm-up · 실전문제(= 0) · 기출(= 99) | `{"drop": [[1, 9], …]}` |

- 지운 덩어리는 글자까지 없앤다. 오른쪽 단을 다 지우면 가운데 점선도. 쏠북은 답 칸 회색 바탕 그림을 뺀다
- `"head": [앞쪽, [x0, y0, x1, y1]]` — 앞 쪽 맨 아래에만 남는 활동 머리를 이 쪽 위로 끌어온다 (그 앞 쪽은 src 에서 뺀다 → 빈 쪽이 생기지 않는다)
- 새 출판사 형식이면 `state()` · `keep()` 에 종류를 하나 더한다

## 점검 (빌드가 멈추는 것)

차례가 한 쪽을 넘음 · 속표지 표가 쪽 아래로 넘침 · 범위 밖 지문이 있는데 지울 표시 줄을 못 찾음 · split 정규식이 안 맞음 · 쪽 수 계산과 실제가 다름 · `exam` 섹션에 `exam_sub` 없음.
