# 단어장 빌더

지문(단원)별 표: 번호 | 단어 | 우리말 뜻 | 덧붙일 열(혼동어·유의어·반의어 … 최대 2개)

```
py 공용/build/단어장/build.py <data.json> [--out 폴더]
```
점검(데이터 → 원문 근거 → 지면 넘침 → PDF 실물)에 하나라도 걸리면 PDF를 내보내지 않는다.
**지면 넘침 점검**: 표가 쪽 아래·오른쪽을 넘거나, 단어·덧붙인 칸이 넘치거나, 뜻이 두 줄로 깨지면 중단한다 → 뜻을 줄이거나 `layout` 을 바꾼다.

예시: `예시/세종예고1_2026-9월학평_단어장.json` (옛 PDF와 쪽별 텍스트 동일 확인 2026-09-18)

## data.json

```json
{
 "school": "세종예고",                 // 선택. 학교/<school>.json 의 wordlist.excluded_labels 를 지면에서 막는다
 "name": "세종예고1_2026-9월학평_단어장_20·21번",
 "source_label": "2026년 9월 인천광역시 교육청 학력평가 &nbsp;|&nbsp; 단어장",
 "grade_label": "고1",
 "title": "WORDS &amp; EXPRESSIONS",
 "title_sub": "2026학년도 2학기 중간고사 대비",
 "footer": "카이젠 나성 캠퍼스 · 세종예고 1학년",
 "color": "#1F4E79",
 "layout": "half",                     // half = 좌우 두 표 / full = 한 표 (덧붙일 열이 2개면 full 권장)
 "columns": [{"key": "confuse", "label": "혼동어", "prefix": "↔ "}],
 "key_suffix": "번",                    // 섹션 머리 "20번" (단원 이름이면 "")
 "per_page": 2,                         // 쪽당 섹션 수, 또는 [2,2,1] 처럼 쪽별
 "per_section": 20,                     // 선택. 섹션당 표제어 수가 정확히 이래야 한다
 "range": ["20", "21"],                 // 선택. 섹션 키가 범위와 같아야 한다
 "grounding": {"bynum": "고1", "round": "2026-9"},   // 선택. 표제어가 그 지문 원문에 쓰였는지 (어형 변화 허용)
 "sections": [
  {"key": "20", "title": "학습 게임은 참여가 목표", "src": "20",
   "items": [{"w": "harder", "m": "더 어려운", "confuse": "easier"}]}
 ]
}
```
- 섹션의 `src` 는 bynum 번호가 key 와 다를 때만
- 어구(공백·~ 포함)는 내용어 하나만 지문에 있어도 근거로 본다
- 데이터 점검: 범위·섹션 중복·표제어 중복·개수·뜻 누락·덧붙인 열이 자기 자신
- PDF 점검: 표제어·섹션 머리 수록 · 강사용 멘트 · "자리" · 잔재 · 빈 쪽 · 학교 제외 유형 표기

## 원본 교재 쪽 끼우기 (양지고2 방식)

원본 단어장이 있는 지문은 그 쪽을 그대로 싣고, 없는 지문만 만든다. 그 섹션은 `items` 없이:
```json
{"key": "21", "items": [], "source_page": {"file": "공용/교재/고2독해/2026/9월/…단어장_21번_….pdf", "contains": "WORDS & EXPRESSIONS"}}
```
- `contains` 글이 있는 쪽이 원본에 정확히 1쪽이어야 한다. 끼우는 섹션은 한 쪽에 혼자 (`per_page: 1`)
- 끼운 쪽은 출판사 글이라 멘트·"자리" 점검에서 뺀다
- 예시: `예시/양지고2_2026-9월학평_단어장.json` (원본 13쪽 + 자체 3쪽, 옛 PDF와 동일)

## 책 형태 (한솔고2 단어장 2권 방식) — `"layout": "book"`

PART 띠 · 목차 · 연속 흐름 · 쪽번호. 지문별 한 쪽 형식이 아니라 한 권으로 이어진다.
```json
{"layout": "book", "school": "한솔고", "name": "한솔고2_2학기중간_단어장2권",
 "title": "한솔고 2학년 … 단어장 <span style=\"font-size:11pt\">2권</span>", "sub": "…", "namebar": "카이젠 어학원 나성캠퍼스",
 "note": "첫 쪽 안내 상자 HTML (선택)", "footer": "…", "syn": false,
 "parts": [{"title": "수능특강 Light 11강", "short": "11강",
            "groups": [{"title": "11강 1번", "items": [{"w": "…", "m": "…", "syn": "…", "ant": "…"}]}]}]}
```
- `syn: true` 면 PART마다 「유의어 · 반의어」 PART가 뒤에 붙는다 (유의어·반의어가 있는 항목만)
- 목차의 수록 개수는 자동 계산
- 예시: `예시/한솔고2_단어장2권.json` (옛 PDF 6쪽과 동일)

## 옮기지 않은 것
- 나성중3 프린트 단어장의 **접두사·영영·다의어 섹션** 구성 — 한 번만 만든 형식이다. 두 번째로 필요해지면 옵션으로 올린다.
