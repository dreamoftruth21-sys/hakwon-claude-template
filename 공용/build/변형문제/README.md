# 학평 변형문제 빌더

## 재조판.py — 시중 변형문제집에서 범위 지문 문항만 다시 모으기

```
py 공용/build/변형문제/재조판.py <data.json> [--out 폴더]
```

원본은 **유형별로 배열된 변형문제집 PDF** (문항 쪽 → 정답표 2쪽 → 해설, 2단, 문항 위 `NN번` 지문 라벨, 쪽 아래 유형명).
- 원래 문항 번호 유지 · 지문별로 모음 · 쪽마다 원문 지문을 왼쪽 위에 한 번
- 원문 그대로인 지문은 문항에서 빼고(발문+선택지만), 밑줄·변형 지문은 통째로
- 원문 지문과 변형 지문을 같은 쪽에 두지 않는다
- 답지 = 원본 정답표에서 범위 밖 번호를 흰색으로 지움
- 점검에 하나라도 걸리면 PDF를 내보내지 않는다 (원본 판독 실패도 중단)

예시 (옛 PDF와 쪽별 텍스트 동일 확인 2026-09-18):
`예시/세종예고1_2026-9월학평_변형문제.json` (고1, 서술형 제외) · `예시/양지고2_2026-9월학평_변형문제.json` (고2, 서술형 포함·오식 교정)

### data.json

| 키 | 필수 | 뜻 |
|---|---|---|
| `name` | ● | PDF 이름 (답지는 `_답지` 가 붙는다) |
| `source` | ● | 원본 변형문제집 PDF (학원 폴더 기준 경로) |
| `question_last_page` | ● | 문항이 끝나는 쪽 |
| `answer_pages` | ● | 정답표 쪽 `[처음, 끝]` |
| `total_questions` | ● | 원본 전체 문항 수 — 판독한 번호가 1~이 수와 정확히 맞아야 진행 |
| `passages` | ● | 실을 지문 라벨 순서 `["21", "41~42"]` |
| `range` | | 시험 범위 — passages 가 벗어나면 중단 |
| `quota` | | 지문·유형별 상한 `{"default": {"대의파악": 1, "어법": 2}, "21": {…}}` — 문항 번호 순으로 앞에서 n개. 적지 않은 유형은 0개. 대의파악은 1개 이상 (쪽 위 원문 지문을 가져온다) |
| `drop` | | 뺄 문항 `[{"sec": "서술형"}, {"sec": "대의파악", "stem_any": ["목적으로"]}]` (sec = 원본 쪽 아래 유형명) |
| `omit_sections` | | 원문과 같을 때 지문을 뺄 유형 (기본 대의파악·내용일치/불일치) |
| `omit_sections_if_stem` | | 발문에 글이 있을 때만 지문을 뺄 유형 `{"서술형": "요약"}` |
| `essay_from` | | 정답표에서 서술형이 시작하는 번호 (그 줄은 한 줄 전체를 지운다) |
| `corrections` | | 원본 오식 교정 `{"33": [["grief work is", "is", "as"]]}` — 쪽 위 원문 지문에서만 |
| `answer_note` | | 답지 첫 쪽 안내 `{"text": "…", "y": 64}` |
| `excluded_patterns` | | 지면에 나오면 안 되는 글 (학교 비출제 유형: `쓰시오`, `영영풀이` …) |
| `bynum` | | 쪽 위 지문을 학평 원문과 대조 `{"grade": "고1", "round": "2026-9"}` — `공용/교재/모의고사/_데이터/` 에 그 회차가 있을 때만 |
| `footer_x_max` · `strict_continuation` · `orphan_ok` · `label_regex` | | 원본 판형 차이 조정 (예시 참고) |

## 기출가공.py — 내신기출·변형문제집에서 지문 단위로 지우기(✕) / 뽑기(새 조판)

```
py 공용/build/변형문제/기출가공.py <data.json> [--out 폴더]
```

| book | 원본 | 지문 판정 |
|---|---|---|
| `내신기출` | 이그잼포유 「내신기출 N회」 (문항에 지문 라벨 없음) | 학평 원문 6-gram (`bynum`) |
| `변형문제` | 이그잼포유 「변형문제」 (문항 위 `NN번` 라벨) | 라벨 |

| mode | 결과 |
|---|---|
| `지우기` | 원본 전체 그대로 + 대상 지문 문항·해설을 흰색으로 덮고 ✕ (범위 밖 지문 지우기) |
| `뽑기` | 대상 지문 문항·해설만 잘라 제목 띠·구획 띠를 붙여 새로 조판 |

예시 (옛 PDF와 쪽별 텍스트 동일 확인 2026-09-18):
| 파일 | 원본 → 결과 |
|---|---|
| `예시/한솔고2_2025-9월_내신기출1회_지우기.json` | 내신기출 24쪽, 25~28·41~45 ✕ |
| `예시/한솔고2_2025-9월_변형문제_지우기.json` · `양지고2_…` | 변형문제 233쪽 ✕ |
| `예시/세종예고2_2025-9월_내신기출1회_뽑기.json` | 32·34·36·40번 → 11쪽 |
| `예시/세종예고2_2025-9월_변형문제_뽑기.json` | 32·34·36·40번 → 44쪽 |

| 키 | 필수 | 뜻 |
|---|---|---|
| `name` · `source` · `book` · `mode` | ● | |
| `passages` | ● | 지울(지우기) / 뽑을(뽑기) 지문 번호. 변형문제 지우기는 묶음 라벨(`25~26`)도 적는다 |
| `bynum` | ● | `{"grade": "고2", "round": "2025-9"}` — 지문 판정·점검 |
| `solution_after_page` | 내신기출 | 문항 마지막 쪽(0부터) — 그 뒤가 해설 |
| `question_pages` | 변형문제 | 문항 쪽 수 — 그 뒤가 정답·해설 |
| `title` · `subtitle` | 뽑기 | 첫 쪽 제목 띠. subtitle 의 `{문항수}` 는 자동으로 채운다 |
| `expect_kept` | | 지우기에서 남아 있어야 할 지문 (지나치게 지웠는지 점검) |

점검: 지우기 — 쪽 수 그대로 · 지울 지문 원문이 문항 쪽에 5% 넘게 남았는지 · 남길 지문이 사라졌는지 / 뽑기 — 뽑을 지문이 다 들어갔는지 · 대상 밖 지문이 15% 넘게 섞였는지 · 빈 쪽 · 쪽번호

원본 파일: `공용/교재/모의고사/2025_고2_9월/2025 고2 모의고사 영어 09월 내신기출문제 1회차.pdf` (2026-09-18 `_정리대기` 에서 복사) · 같은 폴더 `…변형문제 (1).pdf`
제목 띠 글꼴: 옛 판은 Noto Sans CJK KR, 이 PC는 Noto Sans KR/맑은 고딕으로 대체된다 (글자는 같다).
