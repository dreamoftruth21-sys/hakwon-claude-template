# 수업 계획표 — 진도를 한눈에

어디까지 했고 얼마나 남았는지 보는 표다. **A4 가로 1쪽.** 쪽 번호·숙제·자료명처럼 자주 바뀌는 수업 준비 정보는 넣지 않는다 — 그건 그날 `수업안.md` 와 `수업일지.md` 몫이다.
짜는 법·고치는 법은 `수업계획` 스킬.

```
py 공용/build/수업계획/build.py <계획.json> [--today YYYY-MM-DD] [--out 폴더]
```

- 계획.json → 반 `시험대비/<시험>/작업/수업계획/계획.json`
- 결과 → 반 폴더 최상위 `<파일>.html` (화면) + `<파일>.pdf` (인쇄). `--out` 을 주면 그 폴더
- 기준일(`--today`, 없으면 오늘)로 다음 회차 · 지난 회차 · 시험까지 남은 날을 정한다

## 화면

- 위: `끝난 회차 / 전체` · 남은 수업 · 시험까지 남은 날 + 구간별 띠 (구간마다 끝난 만큼 진하게)
- 가운데: 주 × 수업 요일 격자. 줄 머리에 `D-n주`
  - 끝난 회차 — 흐리게 `✓ 끝`
  - 다음 회차 — 굵은 테두리 `다음`
  - 지난 날인데 끝 표시가 없는 회차 — 빨간 점선 `기록?` (일지와 맞출 것)
  - 휴강 — 빗금 · 시험 — 남색 칸
- 아래: 매 수업 · 확인할 것 · 자세한 계획 경로 (있을 때만)

## 계획.json

```json
{
  "제목": "세종예고2 · 2026년 2학기 기말고사 대비 · 수업 계획",
  "파일": "세종예고2_2학기기말_수업계획",
  "연도": 2026,
  "시험": "12/10",
  "시험_메모": "날짜 미정 — 12월 둘째 주로 가정",
  "범위": "영어Ⅱ 2과 본문 + 2026년 10월 학평 10지문",
  "열": [{"이름": "화", "요일": ["화"]}, {"이름": "목", "요일": ["목"]}],
  "구간": [{"키": "본문", "이름": "① 2과 본문", "색": "파랑"}],
  "회차": [
    {"날짜": "10/20", "구간": "본문", "진도": "2과 본문 정독 1/4", "단어": "2과 ①", "끝": true},
    {"날짜": "10/22", "구간": "본문", "진도": "본문 정독 2/4", "확인": "학평 번호 공지"},
    {"날짜": "10/9", "휴강": "한글날"}
  ],
  "매수업": ["단어시험 → 숙제 확인 → 진도 → 숙제 안내"],
  "확인": ["기말 날짜"],
  "상세": ["분석/2026-2학기-기말_수업계획.md — 학생별 추가 과제"],
  "휴일": {"2027-02-08": "설 연휴"}
}
```

| 키 | 뜻 |
|---|---|
| `제목` | 쪽 아래에도 찍힌다. **반 · 연도 · 무슨 자료**를 넣는다 (반 이름이 없으면 멈춘다) |
| `열` | 격자 칸. 요일로 회차를 칸에 넣는다. 나성중3처럼 두 슬롯이 같은 내용이면 `{"이름": "월 · 화", "요일": ["월","화"]}` |
| `구간` | 진도 덩어리 (과 · 학평 · 실전 …). 색: 파랑 초록 주황 보라 빨강 노랑 청록 회색 (빼면 차례대로) |
| `회차.날짜` | `"10/20"` 또는 같은 내용을 두 슬롯에서 나가면 `["9/28", "9/29"]` — 마지막 날이 지나야 끝난 회차로 본다 |
| `회차.진도` | **한 줄.** 무엇을 어디까지 (과 · 단계 · 지문 번호). 38자를 넘으면 경고 |
| `회차.단어` · `확인` · `메모` | 짧게 (선택). `메모` 는 실제로 계획과 다르게 나간 것 |
| `회차.끝` | 수업을 마친 회차 `true`. 수업일지에 기록된 것만 |
| `회차.열` | 요일로 칸이 안 정해질 때 (보강 등) 칸 번호 |
| `회차.휴강` | 빗금 칸에 그대로 찍을 글 (`"휴강 — 한글날"` · `"화목반 추가 수업 — 결석"`). 회차 수에 안 센다. 같은 주 같은 칸에 휴강과 수업이 같이 오면 위아래로 쌓인다 |
| `휴일` | 빌더에 없는 수업 안 하는 날 (음력 공휴일 등). 빌더는 양력 공휴일과 2026 추석 · 대체공휴일만 안다 |

## 점검 — 하나라도 걸리면 아무것도 쓰지 않는다

- 공휴일 · `휴일` 에 잡힌 수업 · 시험 뒤 수업
- 아직 오지 않은 날에 `끝`
- 없는 구간 · 빈 진도 · 칸을 못 찾은 날 · 같은 날 같은 칸에 두 회차
- 제목에 반 이름 · 연도가 없음 · 쪽 번호가 안 찍힘

경고만 하는 것: 지난 날인데 `끝` 이 없음 · 진도가 김 · 1쪽을 넘음 (한 번은 글자를 줄여 다시 맞춰 본다)

예시: `예시/세종예고2_2학기기말.json` (2026-10-13 세종예고2 계획 2판을 옮긴 것)

## 옛 방식

`템플릿.html` + `pdf.py` — 회차마다 쪽 번호·숙제까지 적던 상세 계획표 (나성중3 · 한솔고2 · 양지고2 2학기 기말 첫판). 이미 있는 상세 계획표를 다시 뽑을 때만 쓴다: `py 공용/build/수업계획/pdf.py <계획.html>`
