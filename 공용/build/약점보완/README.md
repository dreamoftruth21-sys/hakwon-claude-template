# 약점 보완 자료 · 약점 확인 시험 빌더

반이 이미 푼 **실전 모의고사 회차들**(공용 모의고사 빌더 형식 data.json)과 **학생 답**으로 학생별 자료를 만든다. 절차는 `약점보완` 스킬.
첫 사례: 세종예고2 2026-2학기 중간 (`세종예고2/시험대비/2026-2학기-중간/작업/개인패키지/` · `확인시험/`). 이 빌더로 옮긴 뒤 여섯 명 자료 24개가 옮기기 전과 쪽마다 같은 것을 확인했다 (2026-09-30).

| 자료 | 실행 | 작업폴더 |
|---|---|---|
| 약점 보완 자료 (문제편 + 답지) | `py 공용/build/약점보완/build.py <작업폴더> 이름 [이름…] [--out 폴더]` | `<반>/시험대비/<시험>/작업/개인패키지/` |
| 약점 확인 시험 (시험지 + 답지) | `py 공용/build/약점보완/확인시험.py <작업폴더> [이름… \| --bank bank_X \| --dup] [--out 폴더]` | `<반>/시험대비/<시험>/작업/확인시험/` |

선택형만 다룬다. 서답형(`kind: short/essay`)은 오답 판정·통계·연습 문제에서 모두 뺀다.

## 약점 보완 자료 — 작업폴더에 둘 것

### 설정.json
```json
{
 "반": "세종예고2",
 "sub": "세종예고 2학년 · 2026학년도 2학기 중간고사 대비 · 실전 모의고사 1~7회 분석",   // 표지 부제
 "answer_sub": "세종예고 2학년 · 2026학년도 2학기 중간고사 대비",                        // 답지 부제 (없으면 sub)
 "footer": "세종예고2 · 2026-2학기 중간고사 대비",                                       // 쪽 아래 — 뒤에 "· 이름 약점 보완 자료 · n / N"
 "file_prefix": "세종예고2_약점보완자료_",
 "out": "../../배부",                                   // 작업폴더 기준
 "methods": "학생설정",                                 // 공용 보완 방법 모듈 이름 (기본 "방법")
 "rounds": {"1": "1회_data.json", "3": "../실전모의고사_3회/data.json"},   // 회차 → data.json (작업폴더 기준)
 "paper_rounds": [1, 2],                                // 종이 시험 회차 — 고른 답이 없다
 "paper_score_unit": {"1": "", "2": "점"},              // 표지 점수 칸 단위 (1회를 "2개"처럼 틀린 개수로 적었으면 "")
 "score_note": "1회: 틀린 개수 · 2회: 종이 시험 점수 · 3~7회: 온라인 첫 제출 점수",
 "textbook_src": ["L1"],                                // 교과서 지문의 src 키 (연습 문제 p1과 필터)
 "textbook_rounds": [1],                                // 전 문항이 교과서인데 src 표시가 없는 옛 회차
 "labels": {"12": "어법 2회"},                           // (선택) 회차 이름 — 종류가 다른 세트를 섞을 때. 없으면 "12회"
 "sub_kinds": {"어법": [["수일치", "단수|복수"], …]}      // (선택) 발문이 같은 유형을 해설(sol) 정규식으로 다시 나눈다. 첫 번째로 맞는 이름
}
```
`labels` · `sub_kinds` 예시: `세종예고1/시험대비/2026-2학기-중간/작업/개인패키지/설정.json` (실전 모의고사 + 어법 세트, 어법을 「어법 핵심 7가지」로 나눔).

### 응시기록.json
```json
{
 "online": {"학생S": {"3": {"ans": "54215423…", "score": 85.7}}},   // 온라인 **첫 제출** 입력 답 (선택형 순서, "-" 는 빈칸)
 "paper": {"학생S": {"1": [25, 26], "2": [7, 9, 20]}},             // 종이 시험 틀린 번호
 "paper_score": {"2": {"학생S": 87.7}},
 "exclude": {"1": [1, 8, 18, 19, 26]},                              // 범위 밖 문항 — 통계·연습에서 뺀다
 "corrections": {"학생U": {"3": {"5": {"entered": 5, "chosen": 3, "note": "…"}}}}   // 입력 실수 기록 (ans 에는 고친 답을 넣는다)
}
```
온라인 답은 구글 시트 「온라인채점」 `제출` 탭에서 가져온다. **`read_file_content` 는 쓰지 않는다** — 검색용 텍스트 사본이라 몇십 분 늦다 (2026-09-30 19:38 제출이 20분 넘게 안 보였다). 드라이브 도구 `search_files`(title = '온라인채점')로 시트를 찾아 `download_file_content`(그 fileId, exportMimeType `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`)로 현재 시트를 받는다. 결과가 크면 파일로 저장되니 JSON `content` 를 base64 디코드해 openpyxl 로 `제출` 탭을 연다. 같은 시험을 여러 번 냈으면 **첫 제출**만 쓴다. 이름 `TEST` 는 뺀다. 시험 기간을 보관한 뒤(중간·기말 끝, 시트 `보관` 탭)에는 그 기간 기록이 「온라인채점 보관 · <이름>」 파일에 있다. `문항별` 13번째 칸 `찍음`(V)은 찍어서 맞힌 문항이다.
시트의 "틀린 번호" 칸은 날짜로 바뀌어 보일 때가 있다 ("7, 9, 22" → "2007, 9, 22") — 틀린 번호는 입력 답과 채점키로 다시 계산한다.

### <methods>.py — 공용 보완 방법
`METHODS = {"요약": "<div class=\"how\">…</div>", …}` · `VOCAB = {"word": "뜻"}` (요약문 선택지 단어표).
예문은 **그 반의 시험 범위 원문**에서 가져온다. 세종예고2 `학생설정.py` 가 예시 — 다른 반은 예문을 그 반 범위로 새로 쓴다.

### 학생_<이름>.py
```python
GROUPS = [{"title": "어법 판정",                 # 약점 이름 (명사구)
   "kinds": ["어법", "어법 개수"],               # 이 약점에 드는 문항 유형 (build.kind) — 통계·연습 문제 필터
   "head": "…",                                  # 표지 약점 목록 한 줄 (명사구, 짧게 — 표지가 한 쪽을 넘으면 멈춘다)
   "how": "<p>…</p>",                            # 「틀린 문제」 표 위 설명 · "col": 표 셋째 칸 머리 (기본 "틀린 이유")
   "habits": [("굵은 머리말(명사구)", "설명")],   # 「원인」
   "methods": ["어법", "개수"],                  # METHODS 키 · "vocab": True 면 요약문 단어표
   "example": (7, 22), "walk": "…",              # 「예제 풀이」 — 그 약점의 온라인 오답 하나 (없으면 빼도 된다)
   "trace": "밑줄마다 O / X 와 근거 단어",        # 다시 풀기·연습 문제 아래 근거 칸 안내
   "wrong": [(2, 9), (3, 5)],                    # 이 약점의 틀린 문항 — 틀린 문항은 빠짐없이 한 약점에
   "p1과": True, "pmax": 8}]                     # 연습 문제: 교과서만(True)/학평만(False)/둘 다(없음) · 최대 수
ITEMS = {(3, 5): {"miss": "표의 틀린 이유 (정답 번호는 밝히지 않는다)", "why": "답지의 틀린 이유"}}   # 온라인 오답 전부. 예제 문항은 why ""
METHODS_EXTRA = {}; VOCAB_EXTRA = {}             # 이 학생만 쓰는 보완 방법 · 단어
```

### 빌더가 막는 것
틀린 문항이 약점에 빠짐 · 약점 유형과 틀린 문항이 어긋남 · 필수 칸 누락 · 온라인 오답의 ITEMS 누락 · 표지가 한 쪽을 넘음 · 쪽보다 넓은 내용(PDF 축소) · 문제편 금지어(하세요 · 판서 · 채점하면 · 학생이 · 배점 · 출제자 · 기록 없) · 설명 글의 "모양" · "나는" · "틀려 보" · "맞아 보" · "자리" · 요약 단어표에 뜻이 없는 단어.
연습 문제는 **학생이 아직 안 푼 회차에서 고르지 않는다** (답지에 답이 실린다). 틀린 문항·앞 약점에서 쓴 문항도 다시 쓰지 않는다.

### 데이터만 쓸 때 (설명 초안을 쓰는 에이전트)
```python
import sys; sys.path.insert(0, r"…\공용\build\약점보완"); import build as B; B.init(r"<작업폴더>")
B.wrong_set(이름) · B.first_ans(이름, 회, 번) · B.chosen(…) · B.disp_opts(회, B.Q(회, 번)) · B.kind(q) · B.D[회]["passages"][키]["body"] · B.plain()
```

## 약점 확인 시험 — 작업폴더에 둘 것

### 설정.json
```json
{
 "school": "세종예고",                                       // 공용/build/학교/<학교>.json
 "title": "2026학년도 2학기 중간고사 대비 <b>약점 확인 시험</b> · %s",   // %s 에 이름
 "subtitle": "…", "footer": "세종예고 2학년 · 영어Ⅱ 약점 확인 시험", "file_prefix": "세종예고2_약점확인시험_", "out": "../../배부",
 "sources_from": "../실전모의고사_7회/data.json",            // 원문 대조용 sources · range_block 을 이 data.json 에서 가져온다
 "banks": ["bank_A", "bank_B", "bank_C"],
 "rounds": {"3": "../실전모의고사_3회/data.json"},           // --dup 가 겹침을 보는 기존 회차
 "pt": {"어법 개수": 4.9, "요약": 4.6},                      // 유형별 배점 — 학교 기말에서 그 유형이 나오는 번호의 배점
 "tests": {"학생S": ["L-어법", "L-22", "H-요약1"]}           // 학생별 문항 id — 약점 순서대로
}
```
학교 규격(문항 수·배점표)은 `profile_override` 로 학생마다 푼다 — 모의고사 빌더의 나머지 점검(원문 대조·누출·학생용 PDF)은 그대로 돈다.

### bank_X.py
`ITEMS = [{"id": "L-22", "type": "어법 개수", "passage": {kind, src, body, restore?, guard?, free?}, "q": {stem, show, fixed, opts, ans, sol, box?}}]`
passage 는 그 문항만 쓰는 단독 지문. `n` · `pt` · `box_ref` 는 넣지 않는다 (조립할 때 넣는다). 형식은 `공용/build/모의고사/README.md`.

온라인 채점: `py 공용/온라인채점/채점키.py <작업폴더>/_json/<이름>.json --id <반>_약점확인_<이름> --open` (`온라인배포` 스킬).
