# 어법 핵심 정리 빌더

시험 범위 원문으로만 만드는 어법 정리 (학생 배부용, 보통 2쪽). **새 반은 data.json 하나만 쓴다.**

```
py 공용/build/어법핵심/build.py <data.json> [--out 폴더]
```
- `--out` 이 없으면 data.json 의 `out`(data.json 기준 상대 경로), 그것도 없으면 data.json 이 있는 폴더
- 예시: `예시/세종예고2_어법핵심.json` (세종예고2 2026-2학기 중간, 9/30 배부본과 쪽별 텍스트 동일 확인 2026-09-30)
- 같은 형식의 옛 자료: 세종예고1 `시험대비/2026-2학기-중간/작업/어법핵심/build.py` (어법 핵심 7가지 — 아직 이 빌더로 옮기지 않았다)

## 원칙 (사용자 지시 2026-09-29)
- **예문은 그 반 시험 범위 원문 문장 그대로.** 빌더가 원문에서 문장 전체를 찾아 넣고, 못 찾으면 멈춘다.
- **개념도 범위 원문에 있는 것만.** 규칙 표의 줄마다 그 개념을 보여 주는 범위 예문이 문서 안에 있어야 한다. 다른 교재(첫단추 · 천일문 등)에서 개념·예문을 가져오지 않는다. 교과서 문법은 교과서에 있는 형태만 (세종예고2: must / may have p.p. 만).
- 점검 순서는 **본동사 → 진짜 주어(수일치) → 하는가 당하는가(행위의 대상이 주어냐 목적어냐 · be + p.p.) → and·or(앞뒤 형태를 맞춘다) → 관계사 → 형용사·부사 → 틀린 것처럼 느껴지지만 옳은 어법** (세종예고2 예시).

## data.json
```json
{
 "name": "세종예고2_2026-2학기중간_어법핵심",          // PDF 파일 이름
 "out": "../../배부",
 "max_pages": 2,
 "title": "세종예고 2학년 · 2026-2학기 중간고사 대비 · 어법 핵심",   // 제목 · 쪽 아래 (footer 로 따로 줄 수 있다)
 "sub": "영어Ⅱ 1과 본문 · 2025년 9월 학평 32·34·36·40번 · … · 예문은 모두 원문 문장 그대로 (✗ 는 틀린 형태)",
 "sources": {                                          // 원본 경로는 학원 폴더 기준
  "L1":  {"name": "교과서 1과", "md": "세종예고2/학교자료/_텍스트/…/1과_본문_….pdf.md", "until": "Read More", "strip": ["소제목", "…"]},
  "A32": {"name": "2025 9월 학평 32번", "bynum": "고2", "round": "2025-9", "num": "32"},
  "B24": {"name": "2026 9월 학평 24번", "pdf": "공용/교재/모의고사/2026_고2_9월/…문제지.pdf", "num": "24",
          "replace_from": "세종예고2/…/실전모의고사_7회/data.json"}      // 문제지의 빈칸·번호를 원문으로 채운다 (또는 "replace": [[바꿀 것, 원문]])
 },
 "check_title": "밑줄 문장 점검 순서",
 "check": ["<b>본동사</b> — 절마다 본동사가 하나 있는가 (1)", "…"],
 "sections": [
  {"n": "1", "title": "본동사 — 동사인가 준동사인가", "rule": "규칙 한 줄 (HTML)",
   "table": [["주어 + 관계절 + ?", "관계절을 빼고 주어의 본동사를 찾는다"]],
   "ex": [{"src": "B34", "find": "Meals that took", "mark": "became", "wrong": "becoming"},
          {"src": "B34", "find": "It was introduced", "mark": ["was introduced", "revolutionized food preparation"], "note": "덧붙임 (HTML)"}]}
 ],
 "css": ""                                             // style.css 뒤에 덧붙일 CSS (간격 조정)
}
```
- `md`: 텍스트 변환본. 한글 줄·`#` 줄을 빼고(`drop_korean_lines`, 기본 true) `until` 앞까지만 쓴다. 소제목은 `strip` 에 넣어 문장에 붙지 않게 한다.
- `bynum`: `공용/교재/모의고사/_데이터/<학년>_bynum.json` 의 원문.
- `pdf`: 학평 문제지 PDF 에서 번호로 자른다. 빈칸·밑줄 번호가 있는 문항은 `replace_from`(실전 모의고사 data.json 의 `sources.M[0].replace`) 이나 `replace` 로 원문을 채운다.
- `find`: 예문 문장을 찾는 앞부분 — 원문에서 **한 문장으로만** 좁혀져야 한다. `mark`: 굵게 표시할 부분(문장 안에 있어야 한다).

## 빌더가 막는 것
원문에 없는 예문 · 두 문장 이상에 걸리는 `find` · 문장에 없는 `mark` · 예문 없는 유형 · 금지어(하세요 · 판서 · 채점하면 · 학생이 · 배점 · 출제자) · 쪽보다 넓은 내용 · `max_pages` 초과(PDF 를 지운다).
