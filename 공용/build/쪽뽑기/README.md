# 쪽뽑기

교재 PDF에서 그날 쓸 쪽만 뽑아 수업 폴더(`3_수업_…`, `4_숙제_…`, 다음 수업의 `2_숙제확인_…_답지`)에 넣는다.

```
py 공용/build/쪽뽑기/extract.py <교재키> <쪽> <저장경로>     # 한 건
py 공용/build/쪽뽑기/extract.py <jobs.json>                  # 여러 건
py 공용/build/쪽뽑기/extract.py --list                       # 등록된 교재
```

- **쪽은 책에 인쇄된 번호로 쓴다** — `"162-165"`, `"68-69,71"`. `교재.json` 의 `offset`(인쇄 쪽 − PDF 쪽)으로 PDF 쪽을 구한다
- 인쇄 쪽 번호가 흩어진 정답지는 `offset` 이 없다 → `"pdf:23"` 처럼 PDF 쪽으로 준다. 어느 쪽에 무엇이 있는지는 `memo` 에 적어 둔다
- 저장 경로는 실행한 폴더 기준 (반 폴더에서 돌리면 `0930수/3_수업_….pdf`)
- 점검: 뽑은 쪽마다 글자·그림이 있는지. 빈 쪽이 있으면 저장하지 않는다. 내콘 부가자료 PDF가 여는 순간 내는 "aes" 경고는 내용과 무관해서 끄고, 이 점검으로 대신한다

jobs.json
```json
[{"src": "내콘중3_중간_L7", "pages": "162-165", "out": "0930수/3_수업_내콘L7_문법_162-165.pdf"},
 {"src": "내콘중3_중간_정답", "pages": "pdf:23", "out": "0930수/3_수업_내콘L7_문법_162-165_답지.pdf"}]
```

## 교재 등록 (`교재.json`)

```json
"내콘중3_중간_L7": {"pdf": "나성중3/학교자료/…Lesson 7.pdf", "offset": 145, "memo": "L7 148~218쪽"}
```
- `pdf` 는 학원 폴더 기준
- `offset` 은 PDF 몇 쪽을 열어 인쇄 번호와 맞춰 보고 정한다 (본권 중간중간 여러 쪽에서 같은지 확인)
- 지금 등록된 것: 나성중3 내신콘서트 L5~L7 본권 · 정답 · L7 부가자료, EXAM4U 7·8과 전부 (2026-09-30). 다른 반 교재는 처음 뽑을 때 등록한다

확인: 2026-09-30 나성중3 `0930수` 파일 4개를 이 도구로 다시 뽑아 쪽별 텍스트가 같은 것을 확인했다.

## 첫 쪽 표식 · 숙제 합본 (2026-10-02)

- `py 공용/build/쪽뽑기/첫쪽표식.py <pdf>…` — 학생 배부 자료 첫 쪽 위 양쪽 모서리에 회색 삼각형(변 약 18mm)을 찍는다. 내용과 겹치면 그쪽만 아래 모서리로 내린다. 이미 찍힌 파일은 건너뛴다. 답지 · 합본에 들어갈 낱개 숙제에는 찍지 않는다
- `py 공용/build/쪽뽑기/숙제합본.py <수업 폴더>` — `4_숙제_*.pdf` 를 `4_숙제_합본_양면인쇄.pdf` 로 합치고 첫 쪽에 표식. 쪽수가 홀수면 빈 쪽을 붙인다 (양면 인쇄). `숙제합본` 스킬이 돌린다
