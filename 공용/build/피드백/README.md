# 시험 결과 피드백 빌더

절차와 쓰는 규칙은 `내신피드백` 스킬. 스크립트를 새로 짜지 않고 json 만 쓴다.

| 문서 | 실행 | 내용 파일 |
|---|---|---|
| 학부모용 한 쪽 (기출분석 표 · 시험총평 · 개별피드백) | `py 공용/build/피드백/부모용.py <content.json> [이름…]` | 반 하나에 json 하나, 학생 여럿 — `예시/부모용_예시.json` |
| 학생용 (결과 요약 · 오답 해설 · 잘한 점 · 아쉬운 점 · 다음 시험 대비) | `py 공용/build/피드백/학생용.py <학생.json>` | 학생 한 명에 json 하나 — `예시/학생용_예시.json` |

- 폴더: `<반>/시험대비/<시험>/피드백/` (학생용은 그 안 `학생용/`). PDF 는 json 옆에 생긴다. 학부모용은 `이미지/` 에 PNG 도 만든다(문자로 보내기용)
- 학부모용은 한 쪽을 넘치거나 머리띠 글자가 잘리면 멈춘다 — 문장을 줄인다
- 학생용은 「틀린 문항 배점 합 + 점수 = 만점」을 대조해 안 맞으면 멈춘다. 부분 점수 · 확인 못 한 점수가 있으면 `"check_total": false` 와 이유 `"check_note"` 를 적는다
- 표 칸(`cols`) 수는 자유다. `table` 각 줄은 `[유형, 칸마다 문항 번호…, 합]`, 마지막 줄은 `["합", …]`
- 시험총평 `review` 는 `"① …"` 처럼 번호 · 띄어쓰기 · 문장
- 첫 쪽 삼각형 표식은 찍지 않는다
