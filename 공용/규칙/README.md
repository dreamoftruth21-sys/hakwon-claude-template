# 규칙은 어디에 쓰나

한 반에서 정한 것이 다른 반에도 적용될 때, 복사하지 않고 **한 곳에만** 쓴다.

| 층 | 적용 | 파일 | 읽히는 방식 |
|---|---|---|---|
| ① 전 반 | 모든 반 | 루트 `CLAUDE.md` | 항상 |
| ② 학교·과목 묶음 | 몇 개 반 | `공용/규칙/<묶음>.md` | 짧은 규칙은 반 `CLAUDE.md` 에서 `@` 로 불러온다(항상). 긴 문서는 경로만 적어 둔다(필요할 때) |
| ③ 자료 종류 | 그 자료를 만들 때 | `.claude/skills/<스킬>/SKILL.md` | 스킬이 쓰일 때 |
| ④ 한 반만 | 그 반 | 반 `CLAUDE.md` | 그 반 세션에서 항상 |

## 새 규칙이 생기면

사용자가 "전 반에 적용", "○○ 공통"이라고 하면:
1. 어느 층인지 한 줄로 확인받는다 — 예: "②세종예고.md 에 넣을까요?"
2. 그 파일 하나만 고친다. 반 `CLAUDE.md` 에 같은 내용을 또 쓰지 않는다.
3. 아래 변경기록에 한 줄 남긴다.

묶음 파일은 **해당 반들 이야기만** 쓴다. 다른 학교와 비교하는 내용은 넣지 않는다.
