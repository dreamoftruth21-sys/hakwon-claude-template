# 시험대비 교재 구성 — 세종예고2 기말 교재 1권 사례 (2026-10-13~15)

**다른 반은 참고만 한다 (10/15 강사 지시).** 교재 구성은 반마다 다르다 — 학교 시험 형식 · 교재 · 학생 수준이 달라서다. 2~5장(무엇을 넣고 어떤 순서로 묶었나 · 책 모양)과 6-2(조판 모양)는 세종예고2에서 강사와 정한 **사례**다. 다른 반은 그대로 옮기지 말고, 이 사례를 보여 주며 그 반 구성을 강사와 새로 정한다.
전 반에 그대로 쓰는 것은 **1장(짜는 순서)과 6-1(품질 규칙)** 뿐이다. 절차는 \교재만들기\ 스킬이 맡는다.

## 1. 짜는 순서

1. **지난 교재에서 실제로 쓴 것과 안 쓴 것을 수업일지로 확인한다.** 실제로 쓴 자료, 앞으로 쓸 자료만으로 구성을 제안한다.
2. 범위를 확정한다. 교과서 본문만인지, 활동 지문이 들어가는지, 학평은 몇 번인지 본다. 활동 지문은 학교가 범위에 더할 때만 넣는다.
3. 원본 교재 쪽수를 세어 예상 쪽수와 함께 구성을 제안한다(`<반>/시험대비/<시험>/교재구성_제안.md`). 승인을 받은 뒤 만든다.
4. **단어장은 샘플을 먼저 만들어 승인받는다.** 그다음 교재에 넣는다.

## 5. 조판 · 빌드 (세종예고2 사례 — 참고)

- 원본 교재 쪽은 모양 그대로 싣는다. 원래 쪽번호는 가리고 교재 쪽번호(`n / N`)를 새로 찍는다.
- 표지(반 · 연도 · 시험 · 단계 흐름 · 이름 칸) → 차례(한 쪽) → 단계마다 **속표지**(단계 이름 · 한 줄 설명 · 들어 있는 것과 쪽) → 내용 → 「정답과 해설」 속표지 → **정답은 교재 단계 순서대로 책 뒤에 통합**한다 (10/15 강사 지시). 속표지는 양면 인쇄의 앞면에 오게 빈 쪽을 끼운다. 표지 · 속표지 · 빈 쪽에는 쪽번호를 찍지 않는다. 첫 쪽 삼각형 표식은 **찍지 않는다** (10/15 강사 지시). 채점용으로 정답 부분만 떼어 낸 파일(`_답지`)도 같이 만든다 — 쪽번호는 책과 같다.
- 날짜별 숙제 쪽은 빌드가 쓴 쪽번호표(`_parts/쪽.json`)로 수업계획 · 계획표에 자동으로 채운다 — 교재를 고칠 때마다 쪽번호를 손으로 옮기지 않는다.
- 교재 안에 필요 없는 안내(범위 밖 지문을 뺐다는 말, 쪽번호 위치, 품사 기호 설명 같은 것)는 넣지 않는다 (10/15 강사 지적).
- 빌드는 공용 빌더 `공용/build/교재/` (10/15 공용화) — 이 교재는 `세종예고2/시험대비/2026-2학기-기말/작업/교재1권/교재.json` 하나로 짓는다. 다른 반은 `교재.json` 만 새로 쓴다 (형식 `공용/build/교재/README.md`).
  - 직접 출제 JSON 은 빌더의 `render.py` 가 조판한다. 출제 규칙은 그 반 `출제지침.md` — 세종예고2 것은 그 학교 출제경향으로 쓴 것이라 형식만 참고한다.

## 6. 직접 만드는 자료 · 조판

### 6-1. 품질 규칙 (전 반 — 10/13~15 강사 지적)

| 항목 | 정한 것 |
|---|---|
| 지문 | **단 · 쪽 경계에서 자르지 않는다** — 지문 상자는 통째로 다음 단으로, "다음 글을 읽고…" 머리는 지문과 붙어 다닌다 |
| 정답 누출 | 같은 쪽 · 같은 회 안에서 한 문항의 지문 · 보기 · 예문 · **안내문 예시**가 다른 문항의 답(고칠 형태 · 정답 낱말)을 보여 주면 안 된다. 밑줄 없는 원문이 바로 옆 밑줄의 고칠 형태를 보여 주는 것도 누출이다 |
| 검증 | 직접 출제한 묶음은 **`검증` 에이전트로 학생 시점에서 전부 풀게** 한다 — 정답 · 복수 정답 · 누출 · 원문 대조 · 강사 말투. 고친 뒤에는 바뀐 문항만 다시 검증한다. 많이 고쳤으면 그 회 전체를 다시 본다 |
| 단어시험과의 관계 | 단어시험은 **학생에게 미리 준 목록에 있는 낱말만** 낸다. 선택지 어휘처럼 새 묶음을 시험에 넣으려면 목록(단어장)을 먼저 나눠 준다 (10/13 — 목록 없이 낸 문항을 채점에서 뺐다) |
| 어휘 문항 낱말 난도 | 문맥상 낱말 문항의 밑줄 낱말은 그 학교 기출 수준에 맞춘다 — 지나치게 어려운 낱말을 쓰지 않는다 |
| 필요 없는 안내 | 범위 밖 지문을 뺐다는 말, 쪽번호 위치, 기호 설명처럼 학생에게 필요 없는 안내는 넣지 않는다 |
| 머리 홀로 남기 | 구획 머리(「N문단」 · 세트 제목 · 「다음 글을 읽고…」)가 쪽 끝에 혼자 남으면 안 된다 — 머리를 첫 내용(첫 문장 상자 · 지문)과 한 덩어리(`break-inside:avoid`)로 묶는다. `break-after:avoid` 만으로는 안 막힐 때가 있다 (양지고2 10/15 강사 지적 — 본문 문장 단어장 「4문단」) |
| 단어장 구획 | 단어장의 ① 핵심 단어 · ② 추가 단어 · 표현 · ③ 유의어 · 반의어 · ④ 암기 확인은 **구획마다 새 쪽**에서 시작한다. 한 구획이 몇 줄만 다음 쪽으로 넘치면 줄 간격을 줄여 한 쪽에 넣는다 (양지고2 10/15 강사 지적) |

### 6-2. 조판 모양 (세종예고2 사례 — 참고)

| 항목 | 정한 것 |
|---|---|
| 시험형 문제 세트 (문법 공략 · 본문 문제 같은 회차형) | **시험지처럼 두 단**(공용 `build/모의고사` 판형), **회마다 새 쪽**, 회마다 머리 상자(제목 · 범위 · 문항 수 · 이름 · 점수) |
| 다른 교재에서 가져온 정답 쪽 | 교재에 넣은 활동의 답만 남기고 **나머지는 글자까지 지운다** — 넣지 않은 단계 · World Link · 뺀 Exercise · 다른 단계에서 쓰는 답. 앞 쪽 맨 아래에 단계 머리만 남으면 다음 쪽 위로 끌어와 빈 쪽을 만들지 않는다 (10/15 강사 지시, `교재.json` 정답 항목의 `clean` · 공용 `build/교재/원본정답.py`) |
| 시험형 문제 세트의 답지 | **회마다 새 쪽** (앞 회 답을 보다 다음 회 답이 보이지 않게) · 맨 위에 **정답 번호표**만 → 그 아래 해설 (채점하기 쉽게, 10/15 강사 지시) |
| 판정표가 붙는 자료 (밑줄 판정 · 개수형) | 한 단 그대로, 표 줄 높이 · 근거 칸을 줄여 **한 쪽에 두 문제**. 한 쪽에 같은 본문이 두 번 오지 않게 배치한다 |
| 정리 칸 (요지 · 주제 · 제목 · 요약 같은 표) | 글꼴은 **세 가지만** — 영어 한 크기 · 한글 한 크기 · 보조 번역은 조금 작은 회색. 한 항목만 굵게 하지 않는다 ("폰트 사이즈 굵기 제각각이라 지저분") |
