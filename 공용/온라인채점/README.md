# 온라인 답 입력 · 채점

학생이 종이로 풀고 휴대폰으로 답을 입력한다. 선택형·기호 단답·인정 답 목록이 있는 단어 쓰기는 제출하면 바로 채점되고, 서술형·목록 없는 단어 쓰기는 답만 기록된다. 모두 구글 시트에 쌓인다.

```
채점키.py                 모의고사 data.json → 채점키/<시험ID>_채점키.json (답지 PDF와 대조, 다르면 멈춤)
해설재료.py · 해설넣기.py · 해설/   결과 화면 해설 (아래 "해설")
정답정정.py · 정정/        배포 뒤 정답 고치기·복수 정답 (아래 "선생님 메뉴")
제안/                     서술형 채점 제안 (서술형채점 스킬)
apps_script/.clasp.json   clasp 배포 설정 (아래 "배포")
채점키/                   드라이브와 동기화된다. 웹앱이 여기 있는 파일을 이름으로 찾는다
apps_script/Code.gs       서버: 채점·시트 기록 (정답은 서버에만 있다)
apps_script/Index.html    학생 화면
```

## 한 번만 하는 설치 (선생님 계정, 약 5분)

> 보통은 처음시작 스킬이 `설치.py` 로 대신한다. 아래는 손으로 할 때의 순서다.

1. 구글 드라이브에서 새 스프레드시트를 만든다. 이름: `온라인채점`
2. 메뉴 **확장 프로그램 → Apps Script**
3. `Code.gs` 내용을 지우고 이 폴더의 `apps_script/Code.gs` 를 통째로 붙여 넣는다
4. 왼쪽 **파일 +** → HTML → 이름 `Index` → `apps_script/Index.html` 을 붙여 넣는다
5. 위쪽 함수 목록에서 `설치확인` 을 고르고 **실행** → 권한 승인(드라이브·시트). 실행 로그에 `채점키 읽음` 이 나오면 된다
6. **배포 → 새 배포 → 유형: 웹 앱** · 실행 계정 **나** · 액세스 권한 **모든 사용자** → 배포
7. 나온 웹 앱 URL을 Claude에게 알려 준다 (아래 "링크"에 적어 둔다)

5번에서 `찾지 못함` 이 나오면: 드라이브 동기화가 아직 안 된 것이다. `채점키/` 의 json 파일을 내 드라이브에 직접 올려도 된다 (파일명으로 찾으므로 위치는 상관없다).

## 새 시험 올리기

```
py 공용/온라인채점/채점키.py <반>/시험대비/<시험>/작업/<자료>/data.json --id <반>_<자료>
```
→ 동기화되면 끝. 재배포할 필요 없다. 학생 링크는 `<웹 앱 URL>?t=<시험ID>`.
`--open` 을 붙이면 결과 화면에 틀린 번호까지 보인다 (기본은 점수와 맞은 개수만).
`--models` 를 붙이면 제출 뒤 서답형(단어 쓰기·서술형)마다 **내 답과 모범답안**을 나란히 보여 준다. **한솔고는 늘 붙인다** (2026-09-28 선생님 요청). 한 번만 제출할 수 있으므로 보여 줘도 된다.

## 문항 입력 방식

| 문항 | 화면 | 채점 |
|---|---|---|
| 선택형 | ①~⑤ 버튼 | 자동 |
| 단답형 — 기호 고르기 (정답이 `ⓐ, ⓑ, ⓒ` 꼴) | ⓐ~ 버튼. 발문에 "있는 대로"가 있으면 여러 개 선택 | 자동 (전부 맞아야 정답) |
| 단답형 — 단어 쓰기, data.json 에 `accept` 있음 | 칸 (1)(2)(3)마다 한 줄 입력 | **자동** (칸별 부분 점수, 2026-09-29~) |
| 단답형 — 그 밖 (단어 쓰기 등) | 한 줄 입력 칸 | 선생님 |
| 서술형 | 여러 줄 입력 칸 | 선생님 |

**단어 쓰기 자동 채점** — data.json 의 단답형 문항에 인정 답 목록을 넣는다 (채점기준 `criteria` 와 같은 내용):
```json
"accept": [["who is"], ["which provides", "that provides"], ["whatever she", "what she"]],
"accept_pts": [2, 2, 2]
```
칸이 하나면 `"accept": [["friction force"]]` 만 (accept_pts 생략). 칸 이름을 (1)(2) 대신 쓰려면 `"accept_labels": ["기호", "고친 표현"]` (한솔고 기호+고친 표현 · Kurzweil/Haraway 칸, 2026-09-30). 기호 묶음(a, c, e)은 순서·쉼표·띄어쓰기를 바꾼 표기를 모두 목록에 넣는다. 비교는 대소문자·앞뒤 공백·끝 마침표·굽은 따옴표를 무시하고 철자는 그대로 본다.
목록에 없는 답은 0점이 된다 — 뜻이 통하는 다른 답을 인정하려면 `문항별` 탭 `득점` 칸을 고친다. `최종 점수` 가 따라 바뀐다.
정오 칸: 전부 맞으면 O · 일부만 맞으면 △ · 0점 X.
자동 채점으로 바꾸기 전에 낸 답('채점 대기')은 편집기에서 `서답형자동채점_기존제출` 을 한 번 실행하면 채점된다 (한 칸에 적은 "(1) … (2) …" 를 나눠 본다. 못 나누면 그대로 두고 로그에 남긴다).

**수학 시험지** (`공용/build/수학` data.json, `"subject": "math"`) — 채점키.py 가 그대로 읽는다.
- **휴대폰 화면에는 수식 · 그림이 나오지 않는다.** 학생은 종이 시험지를 보며 풀고 답만 입력한다. 결과 화면 · 시트의 정답 · 채점 기준은 √ · a/b · ² 같은 글자로 어림해 보여 준다.
- 선택형은 자동. 단답형은 답이 수(정수 · 분수 · 유한소수)면 자동 — 같은 값의 표기(`9/8` · `9 / 8` · `1.125` · `8분의 9`, `1/2` 이면 `0.5` · `.5` 도)를 인정 답으로 펼친다. 근호 · 식 · 좌표가 답이면 입력만 받는다. 더 인정할 표기는 문항에 `"accept": ["5√2", "5루트2"]` 처럼 글자 목록으로 적는다.
- 서술형은 입력만. 채점 단계(`steps`)와 채점 기준이 시트 '서술형 채점' 탭으로 간다.

시험지 PDF의 쪽이 바뀌는 곳에 굵은 줄과 "N쪽" 표시가 들어간다 (채점키.py 가 `배부/<name>.pdf` 에서 읽는다).
서답형이 있는 시험은 결과 화면에 자동 채점 점수와 "선생님 채점 대기 N점 · 서답형 번호"를 따로 보여 준다.

## 해설 (결과 화면 [해설 보기] · 2026-09-30~)

```
해설재료.py <ID> --out 재료.md    채점키 + 원본 data.json → 문항별 지문·발문·인쇄 순서 선택지(✔정답)·원본 해설
해설/<ID>_해설.json              짧은 해설 — 사람(Claude)이 재료를 보고 쓴다
해설넣기.py <ID>                 점검 → 통과하면 채점키에 exp·why 를 넣고 showExp 를 켠다
```
- 제출 뒤 결과 화면 [해설 보기] → 틀린·일부 맞은·선생님 채점 문항이 먼저, 맞은 문항은 [맞은 문항 해설도 보기] 로 펼친다
- **모든 문항**에 exp (두세 줄, 170자 이하). 유형별 틀은 `온라인배포` 스킬 4단계
- **why** (내가 고른 선택지가 왜 답이 아닌지, 90자 이하)는 **어법·어휘 선택형에만**, 정답을 뺀 선택지 전부 — 결과 화면에는 학생이 고른 번호 것만 나온다. 번호는 **인쇄된 번호** (해설재료.py 가 선택지 돌림을 풀어 준다)
- 어법은 **문법 개념 용어**로 쓴다 ("앞의 taking과 and로 이어진 병렬 구조")
- 점검: 모든 문항 exp · why 번호 · 길이 · 금지어(하세요·판서·채점하면·학생이·출제자·배점) · 점수 언급(N점·부분 점수·감점)
- 채점키.py 로 채점키를 다시 만들면 `해설/<ID>_해설.json` 이 있으면 자동으로 다시 넣는다. 다른 스크립트(약점확인·서답형연습)로 만든 채점키는 그 뒤에 `해설넣기.py` 를 한 번 더 돌린다
- 해설은 제출이 끝난 뒤에만 서버가 보내 준다

## 결과 화면 피드백 (2026-09-30)

- 점수 아래 **한마디** — 자동 채점 문항 비율 100 · 90 · 80 · 70 · 60 · 그 아래 여섯 구간. 인터넷 말투 (선생님 결정, "미쳤다" 금지)
- **더 노력할 부분** — 같은 유형 2개 이상 틀림, 또는 2문항 이상인 유형의 절반 이상 틀림 → 많이 틀린 순 최대 3개, 유형별 연습 방법 한 줄. 담담한 말투
- 문구는 `Code.gs` 의 `FB_BANDS` · `FB_TIPS` · `FB_NONE` 한곳에 있다. 고치면 새 버전으로 배포

## 설문 (채점 없음 · 2026-10-06)

채점키에 `"survey": true` 를 넣으면 채점하지 않는 설문 화면이 된다. 문항마다 `q`(질문) · `sub`(보조 설명) · `sec`/`secSub`(묶음 머리글) ·
mode `pick`(보기 `opts` 글자 그대로, `multi` 면 여러 개) 또는 `essay`(쓰기) · `optional`(안 써도 되는 질문). 키 맨 위 `intro` 는 안내문.
- 답은 시트 `설문` 탭에 한 질문 한 줄(제출 시각 · 설문 · 이름 · 시도 · 번호 · 질문 · 답)로 쌓인다. `현황` 등 채점 탭에는 나오지 않는다
- 한 학생은 한 번만 낸다 (TEST 는 몇 번이든). 제출하면 알림 메일에 답이 전부 담겨 온다
- 첫 사용: 세종예고2 중간고사 돌아보기 — `세종예고2/시험대비/2026-2학기-기말/작업/중간고사_돌아보기/make_survey.py` (학생마다 링크 하나, ID `세종예고2_중간돌아보기_<이름>`)

## 시험용 이름 TEST

모든 시험의 이름 목록 끝에 `TEST` 가 붙는다 (Code.gs 가 붙인다 — 채점키·학생.md 에는 넣지 않는다 · 2026-09-30).
TEST 는 몇 번이든 다시 낼 수 있고(시도 1, 2, 3…) 알림 메일이 가지 않는다. 시트에는 기록되니 분석할 때 이름 TEST 는 뺀다.

## 시트

- `제출` — 한 번 제출에 한 줄. **한 학생은 한 시험을 한 번만 낼 수 있다** (2026-09-28부터). 이미 낸 학생이 이름을 고르면 "이미 제출했습니다"와 함께 첫 제출 결과 화면(점수·틀린 번호·틀린 문항의 내 답과 정답)이 다시 뜬다. `--open` 채점키면 결과 화면에 틀린 문항의 정답까지 보인다. 결과는 `문항별` 탭 정오로 다시 만든다. 틀린 번호를 보고 답을 바꿔 다시 내며 정답을 찾던 것을 막는다. 그 전 기록에는 `시도` 2, 3…이 남아 있다. `점수` 는 자동 채점분, `채점 대기` 는 선생님이 채점할 서답형 번호
- 학생이 실수로 잘못 냈을 때 다시 내게 하려면 `제출` 탭에서 그 학생·그 시험 줄을 지운다 (`문항별` 줄은 두어도 된다)
- `문항별` — 한 번 제출에 문항 수만큼 줄. 유형(어법·빈칸·서술형…)·출처(교과서 N과·학평 N번)·학생 답·정답·정오·배점·득점. 약점 분석은 이 탭으로 한다
- **서답형 채점**: `서술형 채점` 탭(아래)에서 한다. `문항별` 탭 `득점` 칸에 직접 넣어도 된다. 한 학생의 대기 칸이 다 차면 `제출` 탭 `최종 점수` 가 "채점 중" 에서 합계로 바뀐다
- `문항별` 13번째 칸 `찍음` — 학생이 [?]로 표시한 문항 (V)

시트 위 메뉴 **[온라인채점]** (시트를 새로 열면 나온다):

|---|---|

| 정답 고친 시험 재채점 | `정답정정.py` 로 채점키 정답을 고친 뒤 시험 ID 를 넣는다. 선택형·기호 단답만 다시 채점하고 `제출` 탭 점수를 다시 쓴다 (단어 쓰기·서술형 득점은 손대지 않는다) |
| 시험 기간 보관 | **중간고사·기말고사가 끝나면** (학기에 두 번) 실행. `제출`·`문항별` 을 새 파일 「온라인채점 보관 · <이름>」으로 옮기고 이 시트는 비운다. 보관한 시험 링크는 "제출 기간이 끝난 시험" 으로 막힌다. `보관` 탭에 기록 |
| 시트 열 때 현황 자동 새로 고침 켜기 | 한 번만 누른다 (권한 승인) |

- **채점 제안**: "서술형 채점 제안해줘" → Claude 가 시트를 받아 채점 기준대로 제안을 `제안/온라인채점_서술형제안.json` 에 쓴다(드라이브 동기화) → 선생님이 [서술형 채점 탭 새로 고침] → 제안 점수·이유가 채워진다. **확정은 선생님이 득점 칸에** (`서술형채점` 스킬)
- **정답 정정**: `py 공용/온라인채점/정답정정.py <ID> <번호> <정답>[,<정답>]` — 복수 정답도 된다. 기록은 `정정/` 에 남아 채점키를 다시 만들어도 유지된다. 원본 data.json·답지 PDF·해설은 따로 고친다
- **보관 뒤 약점 분석**(`약점보완` 스킬)은 보관 파일의 `제출`·`문항별` 탭을 읽는다

## 학생 화면 도움 기능 (2026-09-30)

- **자동 저장** — 입력하던 답·이름·찍음을 그 휴대폰에 저장한다. 창을 닫거나 새로고침해도 남고, 제출하면 지운다. "모두 지우기" 버튼
- **제출 전 한눈에 보기** — 확인창에 `1 ③  2 ①? …` 을 5개씩(쪽마다 줄을 새로) 보여 준다. 빈 문항은 빨강, 찍은 문항은 노랑
- **찍음 [?]** — 선택형·기호 단답 오른쪽. 점수와 관계없다. 찍어서 맞힌 문항은 "더 노력할 부분"·`학생 약점` 에서 틀린 것처럼 세고, 해설에서 틀린 문항과 함께 먼저 나온다("찍어서 맞힘")
  - 결과 화면 점수 아래에 **노란 띠 "★ 찍어서 맞힌 번호: …"** 가 뜨고, 틀린 문항 표 끝에 ★ 줄(내 답 · 정답)로도 나온다. 해설 카드는 노란 테두리 (2026-10-15 · Code.gs `lucky_()`). 이미 낸 학생이 결과를 다시 볼 때도 같다
- **지난 회차와 비교** — ID 가 `<앞부분><번호>회` 인 시험끼리(예: 세종예고1_실전3회 → 4회). "지난 3회 72.5점 → 이번 81.3점 ▲ 8.8" + 많이 달라진 유형 최대 3개. 서답형이 섞여 자동 채점이 100점이 아니면 정답률(%)로 비교

### 코드를 고쳤을 때 배포

`Code.gs` · `Index.html` 을 고치면 `py 공용/온라인채점/설치.py 재배포` — 같은 주소로 새 판이 올라간다. 편집기에서 손으로 고친 것이 있으면 재배포가 덮어쓰니, 먼저 `clasp pull` 로 받아 비교한다.

### 채점키 올리기 (드라이브 동기화 프로그램이 없는 컴퓨터)

`채점키.py` 가 만든 `채점키/<ID>_채점키.json` 을 Claude 앱의 구글 드라이브 커넥터로 올린다 — 드라이브 도구 `create_file` (title = 파일 이름 그대로 · `contentMimeType` `application/json` · `disableConversionToGoogleType` true · `textContent` = 파일 내용). 웹 앱은 같은 이름 가운데 **가장 최근 파일**을 읽으므로, 고친 채점키는 같은 이름으로 새로 올리면 된다. 해설 · 서술형 제안 파일도 같은 방법으로 올린다.
